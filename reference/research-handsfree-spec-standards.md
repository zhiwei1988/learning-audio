# 免提/对讲终端规格标准调研：行业写好了多少，能直接借多少

对应 GitHub issue [zhiwei1988/learning-audio#4](https://github.com/zhiwei1988/learning-audio/issues/4)。

**结论先说**：行业确实已经写好了一整套「拾音 / 放音 / 双讲」的条目清单——但主体骨架来自车载免提（ITU-T P.340 系列），条目名称和测量口径几乎可以整表照抄，**能直接搬的是"清单结构 + 测量方法 + 分级刻度"，不能直接搬的是绝大多数具体限值**（车厢混响、供电、佩戴距离都不是摄像机的条件）。更意外的两个发现：(1) 连行业标准自己的数值也大片留白——ITU-T P.1130（子系统级规格）原文明确写"本版本所有限值均属临时性质，缺乏验证数据"；(2) ETSI EG 202 396-3 和 TS 103 106 实际上**免费公开**，之前 RESOURCES.md 记录的"付费、只能靠应用笔记间接引用"是过时信息，本次已直接下载全文核实。

## 1. 标准家族地图（一段话讲清谁是谁的父子）

```
ITU-T P.340 (2000) —— 免提终端"通用"规格母体
  定义：灵敏度/频响/响度评定/切换参数/双讲分级(Category 1/2a/2b/2c/3)/AEC 功能单元与推荐限值
  │
  ├─→ ITU-T P.1100/1110/1120 —— 车载免提"整机"规格（窄带/宽带/超宽带-全带），直接实例化 P.340 的分级表
  │       └─→ ITU-T P.1130 —— 把上面的"整机"拆成子系统（麦克风/喇叭/AEC+NS/网络传输/短距无线）逐块定指标
  │
  └─→ ETSI TS 103 740 (无线终端, 含手持/车载/桌面/软电话) —— 车载配置直接整条引用 P.1110；
          其余配置沿用 P.340 的双讲分级表（数值原样照抄）；背景噪声质量另起一条线，引用 ETSI TS 103 106

ETSI TS 103 106 ← EG 202 396-3（前身/基础模型）—— 独立的"背景噪声下客观评分算法"，不是终端规格文档本身，
          给的是 N-MOS/S-MOS/G-MOS 三个分数怎么算；谁引用它，谁才给出 ≥3.0 这类门槛（如 TS 103 740 §6.9.2）

ONVIF (Media Service Spec / Profile T) —— 摄像机行业自己的协议层规范，只管编解码格式和网络信令，
          明确声明"回声消除不在 ONVIF 范围内"——完全不覆盖上面这条线的任何声学指标
```

## 3. 逐标准要点（含出处，能给章节号的都给了）

### 3.1 ITU-T P.340（2000/05）—— 母体标准，规格覆盖比想象的深

Lesson 8 只用了它的双讲分级表（§8.1 Table 4），但 P.340 本身是一份完整的免提终端**通用规格**文档，覆盖：

- **§4 Transmission characteristics**：送/受话灵敏度定性要求、频响曲线斜率与滚降规则、响度评定的主观/客观测法、§4.6 切换参数的形式化定义（阈值电平 V_TH、建立时间 T_R、挂断时间 T_H、切换时间 T_S）。
- **§7 Parameters measured instrumentally**：衰减范围 a_H、空闲态衰减分布、挂断时间、动态压缩、混响度、时变传递函数、**双讲行为（duplex behaviour）**、回声消除控制特性、语音检测（含带噪条件）、背景噪声传输——这九条基本就是后续所有子标准条目名称的来源。
- **§8 双讲分级**：Table 4（送话方向 a_H,S,DT ≤3/≤6/≤9/≤12/>12dB 对应 Behaviour 1/2a/2b/2c/3；受话方向阈值 ≤3/≤5/≤8/≤10/>10dB）、§8.2 回声损失分级（TELR_DT ≥37/33/27/21/<21dB）。
- **§9 Table 5**：按 Behaviour 1/2/3 三档给出**设计目标**而非硬限值——例如 Behaviour 2 要求语音检测阈值 <−30dBPa(HFRP)、挂断时间 >50ms（最好>100ms）；Behaviour 3 挂断时间 >250ms；房间噪声检测要求 Hoth 噪声 −50dBPa(A) 持续 10s 不得误触发。
- **§10 Acoustic echo controllers**：定义 AEC 功能框图（图8），§10.2 时延预算（口/耳到网络接口往返 <20ms 期望值，引自 G.174），**§10.3.1 给出房间混响时间的场景化推荐**——这条对摄像机场景极有参考价值（见下表）：

  | 场景 | 平均混响时间 RT60 | 房间体积 |
  |---|---|---|
  | 会议系统（teleconference） | ~400ms | ~90 m³ |
  | **免提终端与可视电话（hands-free terminals and videophones）** | **~500ms** | **~50 m³** |
  | 车载（enclosure 模拟车厢） | ~60ms | ~2.5 m³ |

  摄像机的固定安装场景（客厅/门厅/办公室）在混响特征上比"车载"更接近上表的"免提终端与可视电话"这一档，而不是车载那一档——这是本次调研找到的、**唯一一处标准原文明确给出非车载场景混响参数**的地方。

- **§10.3.2 Parameters and recommended limits**：TCLw（单讲/双讲）、受/送话双讲衰减 A_rdt/A_sdt、双讲失真 D_rdt/D_sdt、建立时间、收敛时间、双讲后挂断时间（要求 THdt=1s 后衰减≥20dB）。**诚实提示**：这一节大量数值原文直接写成方括号占位，例如 "TRst_r shall be no more than **[20 ms]**"、"attenuation... at least **[20 dB]** after THdt = **[1] second**"，且 D_rdt/D_sdt 原文明写"under study"——说明 2000 年定稿时这些数字本身就没有完全定案，只是沿用至今没人再动。

一手来源：ITU-T Rec. P.340 (05/2000)，<https://www.itu.int/rec/T-REC-P.340-200005-I>，全文 PDF 已下载核实（31页）。

### 3.2 ITU-T P.1100（窄带车载免提整机）

读到的是 (10/2008) 版全文（现行版本是 2025/10，未核实是否变更数值）。完整章节：1 Scope /2 References /3 Definitions /4 Abbreviations /5 Conventions /6 How to use /**7 Test arrangement**(含 7.1 车内布置：麦克风典型装在后视镜附近、喇叭装脚窝、HATS 坐驾驶位、四扬声器+低音炮模拟行驶噪声) /8 Digital interfaces /9 Test signals /**10 麦克风测量与要求**(anechoic + in-car 两组) /**11 整机测量与要求**(delay/loudness/frequency response/single-talk quality/idle noise/out-of-band/distortion/echo/double-talk/background noise，12个二级条目) /**12 短距无线(SRW，即车规蓝牙链路)验证** /**13 车对车通信**(主观测试) /Annex A-C /Appendix I。

关键数字已在第 2 节对照表列出。额外值得注意：

- §7.1.8 环境条件默认车内背景噪声 <−54dBPa(A)；§11.6 idle noise 测试要求更严格，背景噪声 <−74dBPa(A)（不超过−64dBPa(A)）——**同一份标准内不同条款对"安静"的定义不一样**，抄的时候要连测量条件一起抄，不能只抄数字。
- §11.10.6 变化回声路径测试用一块 30cm×40cm 反射板绕驾驶位以 90°/s 旋转——这是纯车载几何构造，摄像机场景没有对应物（笔记本翻盖测试见 §3.6 ETSI TS 103 740 更贴近）。
- §12（SRW 验证）本质是把 §10/11 的核心指标在"手机—车机"这条无线链路上重新跑一遍，说明**这套方法论本身支持"分段测"**——这点方法论对摄像机的"MCU 内录 vs 云端解码"分段验收有参考价值。

一手来源：ITU-T Rec. P.1100 (10/2008)（superseded），经 ITU 免费镜像 `T-REC-P.1100-200810-S!!PDF-E` 获取，全文 PDF 已下载核实（102页）。

### 3.3 ITU-T P.1110（宽带车载免提整机）

读到的是 (01/2015) 版全文（现行版本是 2025/10，未核实新版）。章节结构与 P.1100 几乎同构，多出：**15 Corded headsets**、**16 Wireless headsets**（独立成章，P.1100 没有）、**Annex D Standard set of user scenarios**、**Annex E System stability with insufficient far-end echo loss**。

宽带版本的数值和窄带版本**不是简单复制**：

- TCL 门槛从 P.1100 的 ≥50dB（nominal）降到 P.1110 的 ≥46dB（nominal，推荐目标仍是50dB）；
- 频谱回声衰减模板从窄带的 −20~−38dB 收紧到宽带的 −41~−46dB（尤其低频端要求高出一大截）。

说明宽带化之后行业对"高频段可懂度"的容忍空间变小，回声在高频更容易被听出来，所以频谱模板收得更紧——这是一条可以直接讲给团队听的设计意图，而不只是数字搬运。

一手来源：ITU-T Rec. P.1110 (01/2015)（superseded），经 ITU 免费镜像 `T-REC-P.1110-201501-S!!PDF-E` 获取，全文 PDF 已下载核实（114页）。

### 3.4 ITU-T P.1120（超宽带/全带宽车载免提整机）—— 未核实全文

仅确认：标题 "Super-wideband and fullband hands-free communication in motor vehicles"，现行版本 (10/2025)，In force；前一版 (03/2017) 已被取代。两次尝试获取免费旧版 PDF 均返回 "Document Not Found"，当前版本页面无免费下载入口。**结构推断**（非核实）：P.1130 (06/2015) 正文将 P.1100/P.1110 列为参考文献并预留了同类扩展位置，加上 2025年10月 P.1100/1110/1120 三份一起改版，大概率 P.1120 延续同一套章节骨架，只是把频响范围进一步扩展、频谱回声模板可能进一步收紧。**这一条在报告里标记为"查无"，不作为可引用结论使用。**

### 3.5 ITU-T P.1130（车载免提"子系统级"规格）—— 本次调研含金量最高的一份

现行版本 (06/2015)，且**在 2025 年那轮 P.1100/1110/1120 集体改版中没有同步更新**——目前生效的仍是这份十年前的文本，包括它自己声明的"临时性"限值。

这份标准和 P.1100/P.1110 的根本区别：**不是测整机，是把整机拆成子系统逐块定指标**，这正是用户方法论（拾音/放音/双讲三组）想要的分解粒度，比整机标准更贴近"哪个模块该背哪个指标"的产品分工。

- **§7 Architectures**：定义四种物理形态——distributed speakerphone（麦克风、喇叭、算法处理器三者分离）/ system with integrated microphone / system with integrated speaker / system with integrated microphone and speaker。这套分类直接映射摄像机产品线的"一体机 vs 分体对讲基站"划分。
- **§8.3 Acoustic subsystem**：
  - §8.3.1 通用（子系统时钟同步精度、子系统时延、回声路径过载点、加权耦合损耗）；
  - §8.3.2 **Microphone subsystem (send path)**：过载点/频响/空闲噪声/**SNR**/线性度/送话语音质量/带噪送话语音质量——每条都有 "Performance level classification"（多档分级，不是单一 pass/fail）和 "Design guidance and root-cause analysis"（失败时该查什么）两个子条款；
  - §8.3.3 **Audio subsystem (receive path)**：时延/频响/语音质量/空闲噪声（对应喇叭侧）。
- **§8.4 Signal enhancement subsystem**（即 AEC+NS 模块本身，**39 个参数**，是全家族里粒度最细的一份）：送/受话时延、信号电平、AGC、送/受话频响、送/受话 MOS-LQO、可懂度 SII、送/受话 SINR、带外抑制、送/受话失真、加权耦合损耗、回声电平-时间曲线、频谱回声衰减、含/不含背景噪声的初始收敛、动态回声路径（含/不含语音）、激活特性、送/受话衰减范围、**双讲衰减范围（送/受话）**、双讲回声检测、双讲送话衰减、语音回声比、SNR 改善量、通话建立后背景噪声传输、带噪场景下的增强语音质量。
- **§9 Bidirectional transport**（网络编解码那条腿）与 **§10 Unidirectional transport**（短距无线/蓝牙那条腿）分别复刻了一遍时延/抖动/JLR/线性度/频响/空闲噪声/降噪测试/语音质量/稳定性——即"网络传输"本身也被当作一个独立子系统单独定指标，这点对摄像机的"云端语音处理 vs 端上处理"分工划线有直接参考价值。
- **Appendix II Reference-free SNR measurement**：**没有干净参考信号时怎么测 SNR**（用噪声方差跟踪+语音活动检测/语音停顿检测），这是本次调研找到的唯一一份给出"免参考测量法"的文档，方法论可以直接搬到摄像机现场测试（不需要拉一路干净参考线）。
- **Appendix III**：动态测试条件下如何测量并应用脉冲响应轨迹（比 P.1100 的"转盘反射板"更通用，可用软件卷积模拟任意运动回声路径）。

**最重要的诚实提示**：正文原话——

> "Note that all limits in this version of the Recommendation are considered provisional due to the lack of verification data. Furthermore, the interpretation of the performance classes deserves further study."

具体例子：§8.3.2.1.4.3（麦克风 SNR 分级门槛）给出了 Performance Class 1–4 的完整表格框架，但四档车速 ≤80km/h 和 ≤120km/h 的 SNR 数值**全部写的是 "FFS"（For Further Study）**——行业标准自己都没填上这一格。这直接回答了 issue 里"能不能直接借数字"的问题：**结构能借，很多数字借不到，因为原文本身就是空的**。

一手来源：ITU-T Rec. P.1130 (06/2015)，全文 PDF 已下载核实（180页）。

### 3.6 ETSI TS 103 740（宽带无线终端免提，含桌面/软电话配置）—— 之前 RESOURCES.md 未收录，本次新发现

Scope：适用于接入移动网络（GSM/UMTS/LTE/NR/WLAN/WIMAX，及对应电话业务 VoLTE/VoNR/VoWiFi）的无线终端，DECT 不在范围内（转 EN 300 176-2）。**严格来说不直接覆盖摄像机**（摄像机不接入蜂窝电话业务），但它定义的四种物理测试配置里有两种比车载更贴近摄像机的固定安装场景：

- §5.2.1 handheld：HATS 距屏幕中心 42cm（默认）；
- §5.2.2 **vehicle-mounted：整条直接引用 ITU-T P.1110**，不再重复定义；
- §5.2.3 **desktop hands-free terminal**：基于 ITU-T P.581 的桌面 HATS 布置；
- §5.2.4 **softphone**（笔记本/PDA 场景），细分为"内置喇叭+麦克风"和"外置喇叭"两种，外置喇叭配置给出了具体桌面几何：两只外置喇叭间距 80cm，与 HATS 前后 40cm/20cm/40cm 三段式布局（图 5.2.4.2-1）——这是本次调研中唯一一份给出**非车载、固定桌面场景**具体测试几何的标准，比 P.340 §10.3.1 的房间混响参数更进一步给到了摆位尺寸。
- §5.2.5 变化回声路径测试：桌面场景用"移动笔记本上盖"模拟动态反射面，比 P.1100 的转盘反射板简单得多，更适合工程内部自测复用。

§6 codec-independent requirements 的条目清单和数值：

- §6.5 TCL：nominal ≥55dB（推荐目标），所有音量档位下限 ≥46dB；
- §6.6 Stability Loss：所有频率、所有音量档衰减 >6dB；
- §6.7 Double talk：**逐字复用 P.340 的 Category 1/2a/2b/2c/3 数值表**（送话 ≤3/≤6/≤9/≤12/>12dB，受话 ≤3/≤5/≤8/≤10/>10dB，回声损失 ≥27/23/17/11/<11dB），并且额外规定**桌面型终端必须达到 Category 1（全双工），手持型终端至少 Category 2a**——这是全家族里唯一一处把"终端形态"和"双讲最低达标线"直接挂钩的条款，对摄像机这种固定设备的定档很有参考价值。
- §6.9.2 背景噪声下语音质量：**引用 ETSI TS 103 106**，要求 N-MOS-LQOw ≥3.0、S-MOS-LQOw ≥3.0、G-MOS-LQOw ≥3.0；
- §6.10.2 频谱回声衰减模板：−41dB(100Hz) 到 −46dB(3.45–5.2kHz) 到 −37dB(7.5–8kHz)，与 P.1110 几乎一致。

一手来源：ETSI TS 103 740 V1.4.1 (2021-10)，<https://www.etsi.org/deliver/etsi_ts/103700_103799/103740/01.04.01_60/ts_103740v010401p.pdf>，全文已下载核实（45页）。

### 3.7 ETSI TS 103 106 / EG 202 396-3（背景噪声客观评分算法，不是终端规格文档）

两份文档**不给终端限值**，给的是"怎么把一段带噪录音换算成 N-MOS/S-MOS/G-MOS 三个分数"的客观算法：

- **EG 202 396-3**（Guide，informative）：早期版本，本身在 References 里写"Normative references are not applicable"——即它不对任何东西提出强制要求，纯粹是评分模型说明。需要配合 ES 202 396-1（背景噪声录制/回放库）和 EG 202 396-2（网络损伤仿真+主观打分数据来源）使用。
- **TS 103 106**（Technical Specification）：EG 202 396-3 模型的再训练/延续版本，Scope 原文明确写**排除 AI 类语音增强终端**（"devices employing such techniques were not available for training and validation"）——这是一条现成的"免责声明"依据：如果摄像机用了 AI 降噪，这个客观评分模型本身承认自己没在这类设备上验证过，不能直接拿它的分数当金标准。

真正给出**门槛值**的是引用它们的下游文档，例如 TS 103 740 §6.9.2 的 ≥3.0，或者 RESOURCES.md 里已经记录的 HEAD acoustics 3QUEST 应用笔记（间接引用 EG 202 396-3 的实测对比案例）。**这次调研确认可以绕过应用笔记直接读原文**——EG 202 396-3 和 TS 103 106 都是免费公开文档，RESOURCES.md 里"原文付费，只能靠应用笔记间接引用"这条记录需要更新。

一手来源：ETSI TS 103 106 V1.6.1 (2021-07) <https://www.etsi.org/deliver/etsi_ts/103100_103199/103106/01.06.01_60/ts_103106v010601p.pdf>；ETSI EG 202 396-3（版本号页面未逐一确认，内容与引用关系已通过全文核实）。

### 3.8 ONVIF —— 摄像机行业自己的规范，完全不覆盖声学层

- **Media Service Specification** §5.1：强制要求"若支持音频，至少支持 G.711 μ-law（Simplex-Camera Microphone Only, 1ch）"；§5.8 `AudioEncoderConfiguration` 只有三个业务字段：Encoder / Bitrate[kbps] / SampleRate[kHz]，外加组播参数和会话超时——**没有响度、失真、时延、SNR 任何一项声学指标**。
- **§5.14 Audio channel modes**：定义 Send-Primacy 三种模式（`HalfDuplex/Server`、`HalfDuplex/Client`、`HalfDuplex/Auto`），这只是"网络层谁被允许在这一刻发送音频数据"的信令仲裁，跟 P.340 意义上的声学全双工完全是两回事。**原文明确声明**：

  > "Acoustic echo cancellation is out of ONVIF scope."

  这句话直接回答了"ONVIF 音频相关 profile 覆盖到哪里"这个问题——**完全不覆盖回声消除，也就完全不覆盖双讲这组指标的声学部分**。
- **Profile T Specification**：音频对讲通道（Back Channel）要求设备侧解码 G.711 强制、AAC 可选；客户端侧编码同样 G.711 强制、AAC 可选；传输层 RTP/UDP 和 RTP/RTSP/HTTP/TCP 强制，HTTPS/TCP、Websocket 为条件/可选。
- **Profile Feature Overview**（RESOURCES.md 已收录）：Audio Streaming / Audio Output Streaming 均标记 **C（Conditional）**，不是 M（Mandatory）——ONVIF 不强制摄像机必须有音频。

一手来源：ONVIF Media Service Specification (Ver. 24.12) <https://www.onvif.org/specs/srv/media/ONVIF-Media-Service-Spec.pdf>；ONVIF Profile T Specification v1.0 <https://www.onvif.org/wp-content/uploads/2018/09/ONVIF_Profile_T_Specification_v1-0.pdf>；两份均已下载全文核实。

## 4. 可直接搬 vs 必须改写

原则：**条目名称、测量口径（在哪个参考点测、用什么信号、多长积分时间）几乎可以整表照抄**；**具体限值几乎都要重新推导**，因为车载免提的四个假设——固定 50cm 嘴距、~2.5m³ 密闭车厢、发动机/路噪背景、车载电瓶 12V 供电——没有一条在摄像机场景成立。

### 4.1 拾音

| 条目 | 可直接搬的部分 | 必须改写的部分 | 为什么 |
|---|---|---|---|
| 麦克风灵敏度/频响/失真/自噪声（P.1100 §10.1，anechoic 条件） | 测量方法、参考点定义（1m 自由场、300mV/Pa 计算公式） | 数值本身通常不用改——这组是**器件级**指标，和安装场景无关，直接沿用 datasheet 口径即可 | 麦克风本身的物理特性不因装在车上还是摄像机上而变 |
| 环境噪声抑制 D-value（P.1100 §10.2.5） | 计算公式（ITU-T G.111 DELSM）、测量流程 | 目标值和"典型达成值"表（−16~−22dB，按后视镜/遮阳板等车内位置给）**必须重新实测**，摄像机的麦克风到嘴的距离（1–4m 远场）远大于车内（0.2–0.5m），近场假设整体不成立 | 摄像机是远场拾音，P.340/P.1100 的整套响度评定和 D-value 公式都建立在"近场、固定 50cm 参考距离"上（见第 7 课远场笔记） |
| **麦克风 SNR 分级** | 测量方法（P.1130 Appendix II 的免参考测量法直接能用） | **限值本身在源标准里就是 FFS**，无法照抄，必须自己定 | 见空白清单 |
| 空闲信道噪声（P.1100 §10.2.4/11.6.1，−64/−72dBV(P)） | 测量流程（激活信号、FFT 窗口、psophometric 加权） | 数值要按摄像机自己的背景本底（PoE 供电噪声、风扇/云台电机、IR-cut 切换噪声）重新定，车内 idle noise 的构成（发动机怠速、路噪）和摄像机完全不同 | 见 MISSION 里"硬件三条线都要覆盖"——这条本身就是"换器件 vs 调算法"决策要用的锚点 |
| 带噪送话语音质量 N/S/G-MOS（TS 103 740 §6.9.2 引用 TS 103 106，≥3.0） | 客观评分算法本身、三分数分解思路（S-MOS/N-MOS/G-MOS 拆开报，第 4 课已用过这套思路） | ≥3.0 门槛可以作为起点参考，但 TS 103 106 明确排除 AI 降噪终端的验证范围，摄像机若用 AI 降噪需要独立验证或至少标注"未被该模型验证" | 见 §3.7 |

### 4.2 放音

| 条目 | 可直接搬的部分 | 必须改写的部分 | 为什么 |
|---|---|---|---|
| 受话响度评定 RLR（P.1100 §11.3，2±4dB） | 计算公式（ITU-T P.79）、"音量控制范围≥15dB"的设计原则 | 具体 dB 目标要重新定——车内背景噪声通常 45–70dB(A)（行驶噪声），摄像机场景背景噪声可能低至 30dB(A)（安静室内）也可能到 60dB(A)（临街），P.340 §4.2 那段"额外增益至少 10dB 应对房间噪声"的逻辑可以借，数字要按摄像机自己的噪声分布表重算 | 参考第 9 课 playback-spl 计算器的整套逻辑，SPL 天花板取决于听音距离和环境噪声，车载的听音距离（驾驶位到中控台，~0.5–1m）比摄像机对讲场景（可能到 3–5m）近得多 |

| 空闲信道噪声（受话，−53dBPa(A)） | 测量流程 | 数值需要重新定，取决于摄像机喇叭本身的底噪水平和产品定位 | 见第 9 课 THD/底噪讨论 |

### 4.3 双讲

| 条目 | 可直接搬的部分 | 必须改写的部分 | 为什么 |
|---|---|---|---|
| **双讲分级表**（Category 1/2a/2b/2c/3，P.340 Table 4，被 P.1100/P.1110/TS 103 740 逐位复用） | **整张表可以直接搬**——送话 ≤3/≤6/≤9/≤12/>12dB、受话 ≤3/≤5/≤8/≤10/>10dB，这是全行业统一的刻度，第 8 课已经用过，可以放心作为摄像机对讲的验收分级标尺 | 无需改写数值本身，但要重新决定**摄像机产品对应哪个 Category**——TS 103 740 把桌面型终端钉死在 Category 1、手持型放宽到 2a，摄像机（固定安装、无移动场景）更接近"桌面型"，可以参考这个思路定档，而不是照抄车载免提常见的 2a/2b 档位 | 见 §3.6，"终端形态决定最低达标线"这个思路本身就是可以直接搬的方法论 |

| 频谱回声衰减模板（P.1100/1110/TS103740，−20~−46dB 按频段） | 模板形状（低频宽松、中高频收紧的思路） | 具体 dB 值要按摄像机麦克风-喇叭间距和腔体重新测，不能直接套车规数字 | 同上 |
| 变化回声路径测试 | **方法论可以简化复用**——TS 103 740 的"移动笔记本上盖"和 P.1130 Appendix III 的"脉冲响应轨迹卷积"比 P.1100 的"转盘反射板"更适合摄像机内部自测（不需要专门机电装置） | 具体运动模式要按摄像机实际使用场景定义（比如人走近走远、门开关，而不是车窗反射面旋转） | 摄像机的"动态回声路径"来源和车载不同（车载是车窗/后视镜反射变化，摄像机可能是人体移动或云台转动） |
| AEC 处理时延预算（P.340 <20ms 期望值，P.1100/1110 各方向<50ms） | 时延预算方法论本身——第 6 课已经建立了完整的九行账，可以直接把 P.340/P.1100 的时延项作为账本条目补充进去 | 具体预算数字要按摄像机自己的缓冲策略重算（第 6 课已论证缓冲统治时延），车载"≤8ms 留给短距无线链路"这类具体分配对摄像机没有意义（摄像机没有手机中转这一跳） | 见 NOTES.md 已贯穿的"缓冲统治时延"主线 |

## 5. 空白清单——标准里没有、方法本身必须自己造的条目

逐条给出"查无"依据，不是靠印象填的：

1. **远场/多距离拾音下的响度评定与 SNR 门槛**。P.340/P.1100/P.1110/P.1130 全部建立在车载固定 ~50cm 嘴距（HFRP）的近场假设上；P.1130 §8.3.2.1.4 麦克风 SNR 分级表的数值原文自己写"FFS"。摄像机 1–5m 远场场景，行业目前**没有一份免提标准给出对应的限值表**——第 7 课的远场笔记（信噪比随距离平方反比衰减、波束成形 DI 换 WNG）是目前唯一可用的定量框架，但那是从器件 datasheet 反推出来的工程近似，不是标准条文。
2. **腔体/结构对 ERL 天花板的定量关系**。P.340 §10.3.1 只给了"房间混响时间"这一个宏观声学环境参数，没有给"设备自身腔体开孔/软装对 ERL 影响多少 dB"的定量模型——这一条 RESOURCES.md Gaps 已经记录（Microchip 应用笔记只给定性结构建议，没有数字）。
3. **供电噪声耦合到拾音链路的限值**。免提车载标准假设 12V 车载电瓶供电，摄像机是 PoE/DC5V，两者的电源噪声频谱和耦合路径完全不同，行业里没有一份免提标准覆盖这条。
4. **红外补光/IR-cut 切换、云台电机噪声对拾音底噪的贡献**。这是摄像机特有的噪声源，车载免提标准的背景噪声库（ETSI EG 202 396-1 里的行驶噪声库）完全不包含这类瞬态电子噪声，需要摄像机行业自己建库。
5. **AI 降噪/AI AEC 场景下的客观评分适用性**。ETSI TS 103 106 原文明确排除"AI-based speech enhancement techniques"的验证范围；P.1100/P.1110 的评测方法论也是 2008–2015 年代设计的，未考虑神经网络类非线性处理器的行为边界（第 8 课 P.808/DNSMOS 部分已经间接涉及，但那是独立于免提整机标准之外的另一条线）。
6. **摄像机特有的"待机/唤醒"场景下的双讲预期**。所有免提标准都假设"通话已建立"为测试起点（P.1100 §11.12.2 甚至专门测"呼叫建立后的背景噪声传输"），但摄像机对讲经常是"按键触发/APP 唤醒"式的短时会话，激活瞬态（第一句话之前的建立时间）如何影响双讲体验，没有标准覆盖。
7. **摄像机到 APP 端整条链路（含云端转码、CDN、移动网络）的双讲分级**。P.1100/1130 的"网络传输子系统"（§9/§10）假设的是运营商电路域/分组域语音网络，摄像机走的是 RTSP/RTMP/私有信令 + 移动互联网，时延与抖动特性差异很大，双讲 Category 分级表能借用刻度，但需要摄像机自己在真实网络条件下重新标定，而不是照搬"网络时延<150ms"这类电信语境的假设。

---

## 6. 结论回应 issue 的四个问题

1. **每份标准覆盖了什么**——见第 2 节对照表；覆盖最全的是 P.1130（子系统级，39 参数的信号增强子系统清单）和 P.340（母体，条目名称的最初来源）。
2. **能直接搬多少**——**条目名称和测量方法论基本可以整体照搬**（尤其是双讲分级表 Category 1/2a/2b/2c/3，这是全行业统一刻度，P.340→P.1100→P.1110→ETSI TS 103 740 逐字复用了 20 多年）；**具体限值数字大多不能直接搬**，因为车载的近场/密闭腔体/车载供电三个假设在摄像机上都不成立，且连标准自己（P.1130）都有大片数值标注 "FFS" 未定案。
3. **必须自己造的**——见第 5 节，核心是"远场拾音的限值表"和"摄像机特有噪声源（供电/IR-cut/云台电机）的底噪预算"这两块，行业完全没有现成数字。
4. **每条结论的出处**——已在正文标注章节号，能给公开链接的都给了；P.1120 全文未核实，已明确标注；ETSI EG 202 396-3/TS 103 106 之前被记为付费是过时信息，本次已改为一手全文核实。
