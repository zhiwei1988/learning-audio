远场与波束成形速查

评审前扫这一页，或者直接打印带进会议室。数据源：Knowles AN-26、Buck IWAENC 2001、TI TIDUE77、Infineon IM69D130、audioXpress。

一句话

波束成形买的是方向，不是距离。距离靠平方反比定律扣掉的 dB，只能靠更近、更安静、更好的麦克风补回来。

四个能当场算的公式

要算什么公式代入一次
距离带来的损失 ΔL = 20·log₁₀(d₂/d₁) 1 m → 4 m 丢 12 dB；3 m → 10 m 丢 10.5 dB
相加式阵列的增益 G = 10·log₁₀(N) 2 支 +3、4 支 +6、8 支 +9、16 支才 +12
空间混叠（栅瓣）起点 f = c / 2d d=21.25 mm → 8.1 kHz；d=40 mm → 4.3 kHz；d=80 mm → 2.1 kHz
差分式的频率上限 f = c / 4d d=21.25 mm → 4.0 kHz，超过后图形开始变形

c = 343 m/s。孔径 L = (N−1)·d；想在频率 f 上有指向性，大致要求 L ≳ c/2f——300 Hz 需要 57 cm。

正常交谈 ≈60 dB SPL @1 m。datasheet 的 SNR 不是录音信噪比——它是在 94 dB SPL（贴耳大喊）下测的，必须先换成 EIN 再相减。 真实门口场景环境噪声 45–55 dB(A)，把它填进去再看一遍。 读数参考：30 dB 以上干净，20 dB 能用但有底噪，10 dB 语音发虚，0 dB 不可用。 注意最后一列：换一颗 SNR 高 5 dB 的麦 = 白得 5 dB，比加两支麦（+3 dB）更划算，也更便宜。

DI 到底换来什么

混响半径（critical distance）被拉远 10DI/20 倍  ·  DI 4.8 dB → 1.7 倍　DI 6 dB → 2.0 倍　DI 10 dB → 3.2 倍

混响半径 = 房间里直达声与混响声一样大的那个距离。走出去以后收到的主要不再是直达声，而是墙面反射—— 所以指向性真正的产品价值是「可用范围往外推了多少」，不是「增益几个 dB」。

「走出去就救不回来」到底指什么 混响不是噪声，是语音自己的回声，频谱与原声相同，间隙里最响的就是上一个音节的尾巴—— 所以降噪治不了它（NS 假设噪声与语音无关且稳定，三条全不满足）。 被毁掉的是时间包络的起伏：音节空隙被尾音填平，而辅音与词边界的信息就在那些空隙里。信息是被填掉的，不是被盖住的。

去混响算法（WPE、神经网络）确实存在，压的是晚期混响，但假设噪声小、需较长观测、声源一动就失效，且补不回已填平的空隙。 准确说法：丢掉的信息拿不回来，只能部分压掉尾巴，代价还很大。走出混响半径后能动的是物理——装近、加指向性、改房间。

链上位置

逐路 HPF  →  波束成形 BF（合并点）  →  AEC  →  NS  →  AGC
  • BF 在 AEC 之前（TI 参考设计的选择）：AEC 只跑一路，省算力。代价是 AEC 要同时建模回声路径与波束向量，「slows the convergence of AEC」（VOCAL）。
  • BF 在 AEC 之后：AEC 每路各跑一份，回声路径干净、收敛快，但算力 ×N。
  • NS 永远最后：谱减法是非线性的，放在自适应线性滤波器前面会让 AEC 收敛不了。
  • 方向切换 = AEC 重新收敛：典型 1–2 秒，期间可能漏回声。症状「转个身说话就有回声」，调 AEC 参数无解。

与 NS / AGC 速查、AEC 速查 对照读。

规格书写法

  • 禁用「拾音距离 X 米」。改成：在 X 米、环境噪声 Y dB(A) 下的 S-MOS / N-MOS。
  • 要几何：数量、间距 mm、排布、指向类型（相加/差分）、固定还是自适应。
  • 要 DI 曲线（不是单个数字），覆盖 300 Hz–4 kHz。
  • 要 WNG 曲线，或等效的「阵列输出本底噪声 vs 单支麦」。
  • 一致性写进 BOM：灵敏度 ≤±1 dB，相位容差写明角度与测试频率，禁止中途换非匹配料。
  • 结构评审看实物：两路音孔与密封一致性。
  • 联动条款：自适应波束须说明方向切换时 AEC 的处理与收敛时间。
  • 室外加一条：≥3 m/s 风速下开关波束成形的对比录音。

评审提问清单

  • 「间距多少毫米？孔径多少？」——两个数就能封住大半的空话。
  • 「DI 按频率画出来给我看。300 Hz 上是多少？」
  • 「WNG 呢？差分阵列的低频代价你们怎么处理的？」
  • 「麦克风是匹配料吗？灵敏度和相位容差各是多少？」
  • 「固定波束还是自适应？固定的话押的是哪个方向，为什么？」
  • 「自适应切换方向时，AEC 怎么办？收敛要多久？」
  • 「两路音孔的结构一样吗？给我看装配图。」
  • 「关掉波束成形录一段、开着录一段，同一场景，给我两个文件。」
最容易被绕过去的一句 「我们用的是 AI 波束成形。」——AI 不改变孔径、不改变波长、不改变平方反比定律。 深度学习能做的是更好的后处理（分离、去混响、降噪），那属于 NS 那一格， 该用 S-MOS / N-MOS 成对报数来验，不是用米数来吹。
