术语表 · 网络摄像机音频

本课与后续课程共用的词表。产品讨论里请优先使用这些英文缩写，避免「听不清」「有回音」这种不可验收描述。

拾音 / Capture · 放音 / Playback
摄像机麦克风采集环境声（上行）；喇叭播出远端语音/告警（下行）。双向对讲 = 同时或交替使用两者。
SPL · Sound Pressure Level
声压级，单位 dB SPL。0 dB SPL ≈ 人耳听阈；正常对话约 60–70 dB SPL（1 m）；94 dB SPL = 1 Pa，是麦克风灵敏度测试的标准参考声压。
SNR · Signal-to-Noise Ratio
麦克风：参考 94 dB SPL 输入相对自身噪声的比值（常 A 计权）。更高 SNR → 安静环境/远场更干净。不是「灵敏度越高越好」。
AOP · Acoustic Overload Point
声过载点：失真达到阈值（常 10% THD）时的声压级。门铃/门口大喊、关门声需要高 AOP，否则爆音失真。
Sensitivity · 灵敏度
单位声压产生的输出大小。模拟麦：dBV；数字麦：dBFS。灵敏度高不代表音质好；远场可能需要更高有效增益，近场高灵敏度易削波。
Dynamic Range · 动态范围
可线性再现的最强声与最弱声之差。麦克风上常 ≈ AOP − 噪声底。系统动态范围由最弱一环（麦/ADC/算法/编码）决定。
EIN · Equivalent Input Noise
等效输入噪声，单位 dB SPL。麦克风自噪声折算回声学输入。常用近似：EIN ≈ 94 − SNR。远场轻声能否浮出底噪，先看它。
THD · Total Harmonic Distortion
总谐波失真。AOP 常定义为 THD 达到 10%（有的规格用 1%）时的声压。看 AOP 时务必核对 THD 判据。
PDM / I²S
数字麦常见接口。PDM：脉冲密度调制，需时钟与抽滤；I²S：更接近 PCM 采样流。影响布线、抗扰与 SoC 对接，不直接等于音质优劣。
AEC · Acoustic Echo Cancellation
声学回声消除：估计喇叭→麦克风的声学路径，从拾音中减掉「自己刚播出去的声音」。全双工对讲的核心。失败听感：回音、啸叫、远端听到自己。
ANR / NS · Noise Reduction / Suppression
降噪/噪声抑制：削弱稳态或非语音噪声（空调、风噪、马路）。过度则「机器人声」、辅音被削。与 AEC 不同：AEC 针对已知参考（播放信号）。
AGC · Automatic Gain Control
自动增益控制：把忽大忽小的语音电平拉到可用范围。过猛会放大噪声底、引入呼吸感（pumping）。
Full-duplex / Half-duplex
全双工：双方可同时说听（依赖 AEC）。半双工：同一时刻只允许一个方向，用按住说话或 VAD 切换。竞品「自然对讲」通常指全双工。
G.711 · AAC
G.711：8 kHz 窄带电话语音，低带宽低时延，安防机常见。AAC：更高采样率/码率，听感更宽，带宽与算力成本更高。ONVIF 常见枚举含二者。
Far-field · 远场
声源距离麦较远（房间对讲、走廊）。声压随距离约每翻倍 −6 dB。摄像机内置麦多半是远场难题：直达声弱、混响与噪声占比高。
Latency · 端到端时延
从说话到对方听到的总延迟（采集缓冲 + 算法 + 编码 + 网络 + 解码 + 播放）。对讲体验对时延极敏感；算法尾长/缓冲与 AEC 性能常需权衡。
