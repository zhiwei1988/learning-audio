# 双讲组翻译字典

对应 GitHub issue [#10](https://github.com/zhiwei1988/learning-audio/issues/10)。双讲组的两本翻译字典（翻译字典：「意图措辞 → 数值档」的外部可引查表，见 CONTEXT.md「目标值来源」）。选档权归意图册：意图措辞必须钉到能查表的精度。

## 判定规则（Category 怎么定档）

**意图查表定下限档 → 双讲结算算可达档 → 对撞；可达 < 下限走退让程序。**

场景参数不直接映射档位，只从两条路进来：意图侧（这个场景里插话重不重要）、结算侧（物理可达——放音音量/THD → ERLE，结构安装 → ERL，缓冲/尾长 → 时延）。ETSI TS 103 740 §6.7「桌面型必须 Category 1」的形态挂钩**不迁移**（其「桌面」假设 0.5 m 嘴距近场，摄像机 1.5 m 远场 + THD 锁 ERLE，假设全断）；Category 表本身迁移（设备无关的听感分级）。

## 字典一：插话效果 ↔ P.340 Category

字典出处：ITU-T P.340 §8.1 Table 4（送/受话双讲衰减分档），被 P.1100 → P.1110 → ETSI TS 103 740 逐字复用。迁移前提：无——衰减分档是设备无关的听感分级（#4 已证刻度可整表照抄）。

| 意图措辞（用户可观察） | Category | 送话双讲衰减 | 受话双讲衰减 |
|---|---|---|---|
| 像面对面：双方同时说话，谁都不丢字不变轻 | 1 | ≤3 dB | ≤3 dB |
| 能随时插话；我插话时对方那头声音略变轻，但不断 | 2a | ≤6 dB | ≤5 dB |
| 能插话，但我开头一两个字可能被吃掉 | 2b | ≤9 dB | ≤8 dB |
| 插话经常插不进去，基本得等对方停 | 2c | ≤12 dB | ≤10 dB |
| 对讲机式轮流说（半双工） | 3 | >12 dB | >10 dB |

双讲衰减（attenuation during double-talk）：双讲时设备为压回声额外加在语音上的衰减量——衰减越大，被压的那一方越「丢字」。

### TELR_DT 阶梯的两个版本（口径警示）

双讲回声损失 TELR_DT（Talker Echo Loudness Rating during double-talk：双讲时说话人听到自己回声的响度损失，越大越听不到回声）同名 Category 有两版门槛，相差 10+ dB，口径差异未考证（大概率是测量参考点不同）：

| Category | P.340 §8.2（严版） | P.1100 §11.11.3 / TS 103 740 §6.7.3（宽版） |
|---|---|---|
| 1 | ≥37 dB | ≥27 dB |
| 2a | ≥33 dB | ≥23 dB |
| 2b | ≥27 dB | ≥17 dB |
| 2c | ≥21 dB | ≥11 dB |

**方法采用严版**（NOTES 规则：外推一律往坏的方向取整），依据标注须写明两版并存。若将来某机型定档恰好卡在两版之间，那一刻再立 research 考证口径。

## 字典二：交互自然度 ↔ G.114 时延阶梯

字典出处：ITU-T G.114（单向传输时间）+ Fraunhofer AES 6998（双向交互系统时延建议）。迁移前提：**对讲交互性与通话同级**——店铺问价、远程纠正成立；纯喊话/广播场景可放宽到 400 ms。

| 意图措辞（用户可观察） | 口对耳单向时延 | 出处 |
|---|---|---|
| 高交互（抢话、协作指挥不别扭） | ~100 ms 内 | G.114「高交互任务约 100 ms 已明显变难」 |
| 像打电话一样自然 | ≤150 ms | G.114「基本透明」线 |
| 能对上话，但要忍明显的迟滞 | ≤400 ms（须知情标注） | G.114 规划上限 |

配套设备侧字典：双向交互系统时延 ≤50 ms（Fraunhofer）；AEC 处理时延 <20 ms 期望值（P.340 §10.2，引 G.174）。条款拆两条：**设备侧时延预算**（结算层可算可测，绝对值）+ **口对耳时延**（含网络；网络 RTT 假设写成前提行，走验证状态四件套）。

## 示范机型拍板（店铺筒机，来自 #10 决议）

- 插话效果意图：**下限 2b（能插话，开头可能吃字），争取 2a（插话不吃字）**。结算可达 TELR 30–35 dB（严版 2a 要 ≥33，落区间上半段）→ 条款写**保底 2b + 目标 2a 挂前提**（THD 曲线实测、ERL 结构条款做扎实），验收距离 1.5 m（对讲半径）。对撞通过，不触发退让。
- 时延意图：**像打电话 → 口对耳 ≤150 ms 目标**（前提：网络 RTT ≤X，X 由结算层从缓冲账反推）、400 ms 知情上限；设备侧预算 ≤50 ms 目标。
