回答形状库

对应 GitHub issue #13。回答形状：清单条目要求方案商交数的数据形态（见 CONTEXT.md「清单投影」节）。方法固定资产——形状由数据的物理形态决定（资源占用天然是曲线、能力宣称天然是表征、感知量天然是成对差值），不随机型变；今后新的「别被单点骗」教训往先例表落行。

全局规则（写进清单前言，不逐条重复）

不符合条目回答形状的回答（宣传语、单点数、自选条件的数），允许一轮定向追问——追问措辞就是把该条目的回答形状再念一遍；二轮仍不合格即记空白，空白直接进对比表（「此家无数据」是显性劣势）。

形状表

形状适用的数据测量网格（我方指定的参数）
曲线（≥3 点）资源占用随可调量连续变化（尾长-MIPS、尾长-内存、THD-电平）取数点列表（如尾长 32/64/128/192 ms；电平 1/10、1/2、满额定）
档位表格按档交易的资源（电压频率档、采样率档、算法开关组合）行 = 我方档位表；列 = 我方指定的量（峰值不要平均）
表征报告「支持 X」类能力宣称（Smart Amp、AEC 尾长上限、去混响）表征条件（喇叭/腔体/激励信号/口径），按指定测法交报告
成对差值感知/算法族指标（降噪量、ERLE 改善、MOS 类）同场、同素材、成对（processed vs bypass），基线由我方指定

背景段（发出清单携带的上下文）

只含场景事实 + 物理包络输出（工作点、对讲距离、ERL 假设、放音 SPL 目标）。准入判据一句话：缺了它方案商无法正确回答——而不是「有助于对方理解产品」。退让顺序、竞争线、保底值、够用线阈值是我方决策信息，不出门。

多家对比的结论形状

不造加权评分表——权重就是意图册的「退让顺序」，再造一套是同一信息记两遍。对比结论 = 每家一张「不达标/空白条目清单」，谁优谁劣看各自不达标条目落在退让顺序的什么位置：砍在退让顺序尾部的输给砍在头部的。选方案商本质上是「选哪家逼我退得最少、退的都是本来就愿意退的」。
