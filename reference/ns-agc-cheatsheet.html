NS / AGC 与处理链顺序速查

评审降噪与增益卖点时扫这一页。用语对齐 WebRTC APM、Q-SYS AEC 白皮书、ITU-T G.160 与 ETSI 3QUEST。

一句话

上行：HPF → AEC → NS → AGC。下行：AGC / 限幅 → 分叉（喇叭 + AEC 参考）。 参考必须取自最终送到功放的那一点。

顺序与理由

位置 模块 为什么在这 放错的听感
1 HPF 高通 先扔掉直流偏置与低频隆隆声（风、云台马达、触碰噪声），后级少扛无用能量 不做：风噪吃满动态；拐点过高：人声变薄
2 AEC 需要线性、未动过增益的麦信号才能拟合回声路径 放后面：回声被前级揉过，收敛不了
3 NS / ANR 收尾清洁 AEC 与波束成形留下的环境噪声 放 AEC 前：谱减非线性拖垮自适应滤波
4 AGC 非线性/时变增益必须在 AEC 输出侧 放 AEC 前：AEC 追着 AGC 跑，回音时好时坏

收敛量级（Q-SYS）：初始收敛约 1–2 s，完全收敛约 10 s 不间断远端语音。 每隔几秒动一次的增益 = AEC 永远收敛不完。

NS：必须成对报的两个数

指标族 出处 量什么 不量什么
SNRI / NPLR / DSN / TNLR ITU-T G.160 信噪比改善、噪声电平下降、两者一致性 不量语音质量与语音失真
S-MOS / N-MOS / G-MOS ETSI EG 202 396-3（3QUEST） 语音质量 / 噪声质量 / 综合，带噪场景 单看 G-MOS 会掩盖取舍
滑杆效应（实测） 两台机 G-MOS 2.2 vs 2.3 几乎相同，但 S-MOS 1.3 / 2.4、N-MOS 4.7 / 3.2 天差地别—— 差异来自降噪 aggressiveness 的实现：激进 = 噪声干净但语音削坏；保守 = 语音保住但噪声漏出。 只给一个数字的降噪规格 = 没有规格。

AGC：三个时间常数

参数 作用 锚点（MAX9814） 调错的听感
attack 信号变大时压下去的速度 约 1.1 ms 太慢 → 起音瞬间过冲/削波
hold 压住后保持的时间 固定 30 ms 太短 → 词间隙就开始回升
release 信号变小后增益回升的速度 attack∶release = 1∶500 / 1∶2000 / 1∶4000 太快 → pumping / breathing，底噪一波波涌
增益范围 可调节的总量 最大 AGC 衰减 20 dB 范围过大 → 静音段把底噪抬到刺耳

口诀：压得快、放得慢。release 通常比 attack 慢 2–3 个数量级。

AGC 救不回来的 采集端已削波（超 AOP 或 ADC 满量程）→ 信息已丢，数字 AGC 只是放大失真。

模拟增益 vs 数字增益

模拟增益（PGA）数字增益
位置ADC 之前ADC 之后
改变 SNR会（决定占满 ADC 量程多少）不会（信号与底噪同步放大）
买到什么动态范围的位置只是响度
该怎么用设计时静态标定一次，之后不动运行时的那个 AGC，放 AEC 之后
  • 数字 MEMS 麦（PDM/I²S）：ADC 在麦壳内，主控没有模拟增益可调——灵敏度在选型时锁死，AGC 必然纯数字。
  • 模拟麦 + codec PGA：有模拟增益，也正是风险所在。运行时动它 = 回声路径幅度变 = AEC 追着 AGC 跑。
  • 要动就必须让 AEC 知道：WebRTC APM 的做法是 set_stream_analog_level() 先告知当前硬件电平，recommended_stream_analog_level() 取回建议值。变化对 AEC 可见，而非偷偷改。
  • 评审三问：① 麦是数字还是模拟、模拟增益谁在调？② 增益变化有没有告知 AEC？③ codec/驱动层的硬件 AGC 关了没有？

典型症状：「刚接通几秒有回音，然后好了，对方一大声又回来」= 模拟 AGC 与 AEC 打架的正反馈。

失败听感 → 先查什么

听感 优先怀疑
安静时沙沙一阵阵AGC release 太快 / 无噪声门
人声发闷、辅音丢NS 过激进（S-MOS 差）
金属「叮叮」、水声musical noise（谱减孤立谱峰）
开降噪后回音更明显顺序/参考错位（NS 或增益跑到 AEC 前）
音量忽大忽小AGC 目标电平 / 时间常数，或未启用
大喊时爆音器件 AOP / ADC 削波，不是算法问题
只有回音、噪声正常回 AEC 速查：参考、耦合、双讲

算力量级（TIDA-01589 实测，C5517）

算法MIPS 平均 / 峰值
固定波束成形9.2 / 9.3
噪声抑制 ASNR13.2 / 13.5
HD AEC113.1 / 131.1
整套 DSP 应用136.6 / 157.3

读法：AEC ≈ NS 的 8 倍算力，独占约 80% 预算。「加降噪」几乎免费，「加真全双工」很贵——这解释了大量低成本机型的取舍。

评测最小矩阵

  • 噪声：≥1 种稳态（空调/风机）+ ≥2 种非稳态（车流、雨、人声嘈杂）。非稳态最难，必测。
  • 条件：噪声电平、说话距离、音量档（对讲默认 + 最大驱离）全部写进报告。
  • 陷阱：安静房间成绩不预测带噪成绩——别用静室 MOS 代替带噪评测。
  • 联测：算法指标在 AEC 开启下测；结构指标（ERL / 尾长）按 AEC 速查 关算法测。
