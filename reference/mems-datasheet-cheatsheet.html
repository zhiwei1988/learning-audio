MEMS 麦克风 Datasheet 速查

评审选型时扫这一页。定义对齐 ADI / Infineon 应用笔记的常见写法；具体器件以 datasheet 脚注为准。

统一测试锚点

灵敏度与 SNR 几乎总是在 1 kHz、94 dB SPL（= 1 Pa） 下给出。比较两颗麦时，先确认是否 A 计权、带宽、供电与接口模式一致。

指标 常见单位 一眼读法 摄像机产品含义
Sensitivity dBV（模拟）
dBFS（数字）		 94 dB SPL 时输出多大；不是音质分 匹配前端增益；远场可能需要更大系统增益，但高灵敏度≠更远
SNR dB(A) 94 dB SPL（1 Pa）@1 kHz 参考 − 自噪声
器件指标，不是录音的信噪比		 安静/远场人声是否干净；越高越好（同价位优先）。横比先核对计权、带宽、时钟模式
EIN / Noise floor dB SPL ≈ 94 − SNR 比该值更轻的声音会被自噪声盖住。实际录音信噪比 = 到达声压 − EIN
AOP dB SPL THD 达到阈值（常 10%）的声压 喊叫、关门、警报是否炸麦；门铃/门口很关键
Dynamic range dB ≈ AOP − EIN 小声与大声是否都能扛；系统还要看 ADC/算法
THD % 给定 SPL 下的失真 大信号是否「糊/破」；常与 AOP 曲线一起看
Frequency response / LFRO Hz / dB 通带平坦度、低频滚降 语音可懂度主要在中频；过低 LF 有时有助风噪/结构噪声
PSRR / PSR dB 电源噪声抑制 摄像机板上开关电源、IR-LED 纹波是否进音频
Interface Analog / PDM / I²S 输出形态与时钟 布线抗扰、SoC 接口、双麦同步难度

数字麦灵敏度速算

数字输出满幅通常映射到最大可接受声压。常见关系（峰值约定下）：

Sensitivity (dBFS) ≈ 94 − Maximum acoustic input (dB SPL)

例：最大 120 dB SPL → 灵敏度约 −26 dBFS。在 DSP 里乱加数字增益会提前削波，等效降低 AOP。

选型一句话

  • 远场听清人声 → 优先 SNR（及结构/算法），别迷信灵敏度
  • 门口大动态事件 → 优先 AOP / THD vs SPL
  • 双麦阵列 → 额外看灵敏度与相位一致性（part-to-part matching）
  • 整机 → 麦指标是上限，腔体、ADC、编码、NS 都可能拖垮
