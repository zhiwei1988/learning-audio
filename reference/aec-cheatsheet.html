AEC 与全双工速查

对讲评审时扫这一页。概念对齐 ADI AEC 说明与 TI 近场全双工参考设计用语。

一句话

AEC = 用播放参考估计「喇叭→麦」路径，从拾音里减去回声。没有可信 reference，就没有真正的全双工。

信号角色

名称 是什么 搞错时的症状
Far-end / Reference 即将（或正在）播放的远端信号副本 回音消不掉；或误消本端语音
Near-end 现场说话人（希望保留） 被当成回声削减 → 双讲损伤
Echo / Tail 参考经声学路径的延迟与拖尾；可覆盖时长 ≈ N taps / fs 尾长不够 → 残余回声；过长 → 算力/时延成本。贴硬墙通常比自由场更长
量尾长 关算法扫频→反卷积 h(t)；或 xcorr / 收敛系数 / 加长 taps 看 ERLE 阈值（−40/−60 dB 或噪声底）与安装面必须写进规范
ERL / 隔离 dB AEC 关、近端静：L_ref − L_mic（同带宽）；结构指标 差：可负～个位数；可干活：≳6–15 dB；好：≳15–30 dB。必写音量/安装面
ERLE AEC 开：算法额外衰减 与 ERL 勿比大小；线性常见 ~20–30 dB
RES / NLP 线性滤波后的残差/非线性抑制（≠自然语言） 过猛 → 断续、空洞；过弱 → 大音量仍回

AEC vs NS vs 半双工

解决什么 需要参考？ 典型失败听感
AEC 喇叭回灌的远端声 是 听到自己；双讲卡顿
NS / ANR 环境噪声 否 机器人声、辅音被削
半双工 用互斥回避回声 否（靠切换） 抢话、一方突然静音

验收最小集

  • 单讲：远端说，近端静 → 远端不应听到清晰回声
  • 近端单讲：近端说，远端静 → 语音清晰、无「空洞切削」
  • 双讲：同时说 → 双方可懂（这是全双工真门槛）
  • 音量扫描：喇叭多档；开大后回声/失真是否恶化
  • 结构：AEC 关测 ERL/隔离（默认对讲 + 最大驱离 × 贴墙）；改布局先比 ERL 再调 NLP
  • 结构扰动：换壳/贴墙/开门后是否需重收敛时间可接受

评审三问

  1. 规格写的是全双工还是半双工？
  2. AEC 的 reference 是否与真实功放输出一致（音量/EQ/限幅）？
  3. 加大喇叭竞争力时，是否同步预算了耦合隔离与残差抑制？
