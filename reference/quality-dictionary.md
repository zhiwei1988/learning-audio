# 音质组翻译字典

对应 GitHub issue [#15](https://github.com/zhiwei1988/learning-audio/issues/15)。音质意图四维度与距离档判据的翻译字典（翻译字典：「意图措辞 → 数值档」的外部可引查表，见 CONTEXT.md「目标值来源」）。

**本字典只收措辞与刻度出处。** 五处疑似空白的外部核查在 [#27](https://github.com/zhiwei1988/learning-audio/issues/27)（一手核查记录：[research-quality-dictionary-gaps.md](./research-quality-dictionary-gaps.md)），[#28](https://github.com/zhiwei1988/learning-audio/issues/28) 已把核查结论落回本表——确认查无的刻度按 #9 规则放弃绝对目标值，改差值/成对或参考期望。目标档、地板档、判据配级、退让序号由意图册拍板——**字典给选项，选档权归意图册**（2026-08-11 边界决议）；示范机型的拍板与取值回填在 [#31](https://github.com/zhiwei1988/learning-audio/issues/31)，按判据级反推距离的参数化工具在 [#30](https://github.com/zhiwei1988/learning-audio/issues/30)。

## 判据阶梯（距离档「判据」列的取值域）

判据：分层承诺表每个距离档承诺的「听到什么程度」。距离数字由它推出——判据不写明，距离就是悬空数（#15 的根因之一：「8 m」承诺的是检出还是逐字，差好几 dB）。

语音类距离档（监听／对讲／语音放音）共用三级：

| 级 | 用户可观察措辞 | 刻度与出处 | 状态（#27 核查后） |
|---|---|---|---|
| ① 检出级 | 听得出有人说话，判断得出情绪与大致意图，逐字听不全 | **查无**——IEC 60268-16 低段边界量化的是词/句识别率，不是「听出有人/情绪」；DORI 确认无音频对应物；SRT 的 50 % 正确率判据语义不匹配（[#27 一手核查](./research-quality-dictionary-gaps.md)） | 查无 → 该级条款放弃绝对目标值，改差值/成对或参考期望（#9）；内部推导可自设假设门槛，但必须标「无外部字典」 |
| ② 逐字级 | 能逐字听懂说了什么 | STI（Speech Transmission Index，语音传输指数：量语音的调制细节被噪声/混响抹掉多少，0–1 打分；0.45 上下勉强能懂，0.60 以上良好）。出处：IEC 60268-16 | 可引 |
| ③ 辨识级 | 能辨认是谁在说，回放可当纠纷证据 | ENFSI FSA-BPM-003（欧洲法庭科学网络·法庭语音比对最佳实践手册，一手核实）：有效语音 **≥约 10 s**（§9.1，软下限——「不足 10 s 预期不含足够说话人特征」）、数字化 **≥44.1 kHz/16-bit**（§8.2.2）；SNR/带宽门槛标准明确只给定性（§9.2） | 软门槛可引——**不产距离，只产前提清单**；「声学质量够不够用」判断权在鉴定专家，条款最多写参考期望 |

STI 迁移前提：源自广播/会场可懂度验收，假设听的是自然语音——摄像机监听/回放场景成立。#28 复核结论：**判据列的 STI 验收口径 = 算法 bypass 的采集链**——判据管「物理上够不够得着」，降噪/编码的加工副作用归「说话自然度」条款管，两条不混测。

提示音档（非语音）不用这套阶梯，单独两级，#27 核查后刻度链条齐全：

- **听得见**：提示音 ≥65 dB(A) 且超环境噪声 ≥15 dB（ISO 7731 §4.2.2/§6.2，「充分但非必要」——频谱/节奏与环境差异大时可放宽）。可由 SPL 对底噪裕量物理反解距离。
- **立刻分得清是哪类**：两条设计约束——种类 **≤6 种**（Patterson 1990 实测：未训练听者一次最多可靠分清约 6 种警报音；迁移前提：文献语境是固定场所/可能受训的听者，摄像机「零训练、注意力分散」场景应更保守，6 是乐观上界）；类型间用**时间模式（节奏）区分而非音色**（ISO 8201 的 T3 三脉冲先例刻意不规定频谱；Patterson 混淆分析：共享节奏的警报音即使频谱差异大也容易混淆）。

## 维度一：说话自然度（拾音向）

降噪（NS）与自动增益（AGC）副作用的家：吃字、「水下咕噜声」（音乐噪声）、背景噪声忽强忽弱（pumping）。

| 档 | 用户可观察措辞 |
|---|---|
| 高 | 听不出加工痕迹：不吃字、无水声、背景噪声平稳 |
| 中 | 有痕迹不碍事：偶尔字头轻、噪声轻微起伏，内容和语气完整 |
| 低 | 痕迹明显：吃字/水声常见，能懂但费劲 |

刻度：P.835（ITU-T 主观听音打分标准：对同一段带噪语音分别打语音失真 SIG、背景噪声 BAK、总体 OVRL 三个 1–5 分——拆三分才看得见「降噪按下葫芦浮起瓢」）。

条款形式（#8 规则，感知族）：**同场、同素材、成对差值**——与关闭降噪的 bypass 对照报三分差值，绝对分不进条款。

差值判定式（#28 方法默认，标注可改）：**成对差值的 95 % 置信区间下界 ≥ 0（统计上显著不劣化）**。依据：P.800/P.800.1/P.800.2/P.835 四份一手核实均无 JND 数字，P.800.2 §9 明文「统计分析不在本建议书范围内」（#27）——无外部数可借，自定绝对门槛不合法（#9），统计判定不需要发明数；P.800 Annex E 的 CCR 成对比较法方向背书。若日后自建 2AFC 配对辨异实验，可换成实测门槛。

## 维度二：安静干净度（双向，投影两条条款）

设备自噪声的家。拾音向 = 录音底噪；放音向 = 喇叭待机嘶声（idle noise，空闲信道噪声：通话建立但无人说话时链路里残留的噪声）。

| 档 | 用户可观察措辞 |
|---|---|
| 高 | 夜深人静时，半米内听不出设备嘶声；回放安静时段同样干净 |
| 中 | 凑近能听到轻微嘶声，正常距离注意不到 |
| 低 | 明显可闻 |

刻度：物理量族，绝对值合法（#8）。测量口径借 P.1100 §11.6（送话 <−64 dBm0(P)、受话 <−53 dBPa(A) 是**车载限值，数字不借**——#4 已证限值几乎全要重推，只借「在哪测、什么加权」）。另有天然差值判据：设备自噪声低于安装场景夜间底噪，即「听不出」。

## 维度三：大声不破音（拾音向）

麦克风声学过载点（AOP，Acoustic Overload Point：麦克风开始削波的声压级，第 2 课）与增益链削波的家。

| 档 | 用户可观察措辞 |
|---|---|
| 高 | 贴着设备喊叫，录音不劈不炸 |
| 中 | 收银台前的大声争执，录音完整可辨 |
| 低 | 正常说话不破即可 |

刻度：物理推导——场景事实册「最近可能声源的距离与类型」→「SPL @ 麦克风位置」（口径规则：任何输入 SPL 必须带测量位置）→ AOP 下限。换算式（#28 定案）：

> AOP 下限 = 声源 SPL@1 m + 20·log₁₀(1 m ÷ 最近距离 m) + 语音峰均比裕量 ≈12 dB

峰均比出处：Merlijn van Veen，语音典型 10–12 dB（RESOURCES「峰均比」条）。声源 SPL 由场景事实册供数——本表与措辞里不出现 dB（意图册入口无 dB 自检）。

## 维度四：放音音色（放音向）

频响与腔体谐振频率的家（Fo：喇叭低频下限，Fo 以下不出声，装进小腔体还会抬升——第 9 课）。

| 档 | 用户可观察措辞 |
|---|---|
| 高 | 语音自然饱满，听得出是「一个人」不是「一台设备」 |
| 中 | 清晰不闷，电话听筒的水准 |
| 低 | 能懂，但明显发闷或发尖 |

刻度（#27 核查后）：频响容差模板**形状**借 P.1100 Table 11-2（受话频响，数值重推）。「闷/尖」措辞的外部对照一半找到：

- **「尖」**= DIN 45692 心理声学锐度（sharpness，单位 acum；1 acum 锚点 = 1 kHz 窄带噪声、带宽 <150 Hz、60 dB。一手：HEAD Acoustics《Psychoacoustic Analyses I》应用笔记，算法出处标注 DIN 45692）。连续量、无「多少 acum 算尖」的固定阈值——只作**同场差值的旁证**。迁移前提：模型在机械噪声/NVH 域标定验证，对回放语音是跨域外推，用前需做一轮「锐度差值 vs 主观闷/尖」相关性小实验。
- **「闷」**查无独立标准量（#27）——按 #9 差值化：同场 A/B 成对主观判定，频响滚降陈述（「2 kHz 以上跌了几 dB」）作物理旁注。

## P.1100 §11 条目映射（#28 定案）

P.1100（ITU-T 车载免提整机规格）§11 的七项条目在本方法里的归宿——**只借条目清单与测量口径，数值一律重推**（#4 已证车载四假设在摄像机上全不成立）。频响、失真各拆送/受两向，七项落成九行：

| P.1100 §11 条目 | 归宿 | 处置（#8 测法三级 + #9 两线框架推导） |
|---|---|---|
| 响度评定（SLR/RLR，§11.3） | 被分层承诺表吸收 | 放音响度已在物理包络（SPL@距离），拾音响度由拾音距离承诺；不另立条款 |
| 频响·送话向（§11.4） | 拾音组·音质，支撑判据列 | 物理量族 → **转举证**：逐字级判据（STI）依赖链路带宽，方案商交频响报告（口径我方指定，算法 bypass 链） |
| 频响·受话向（§11.4） | 放音音色 | 容差模板形状借 Table 11-2，数值按在手喇叭重推 |
| 单讲音质 MOS（§11.5） | 说话自然度 | 感知族 → **差值化**：对 bypass 同场同素材成对，P.835 三分 |
| 自噪声 idle noise（§11.6） | 安静干净度（双向两条） | 物理量族 → **绝对值合法**，只借口径（测点/加权），限值重推 |
| 带外信号抑制（§11.7） | 拾音组·音质附属 | 无独立意图维度（混叠伪影最终伤自然度/音色）→ 提问清单**报数条目**，不设绝对目标值 |
| 失真 THD·送话向（§11.8） | 大声不破音 | 物理推导：AOP 下限换算式（见维度三） |
| 失真 THD·受话向（§11.9） | 已被持有 | 放音 THD 已在物理包络「音量↔THD 曲线」与双讲结算（ERLE ≤ −20·log₁₀(THD)）里，不另立 |
| 背景噪声传输 D-value（§11.12） | 并入说话自然度 | 近场假设断（车内 0.2–0.5 m vs 摄像机 1–4 m，#4），数值不迁移；用户可观察面 = BAK 分，已在 P.835 三分差值里 |
