# 退让程序

对应 GitHub issue [#7](https://github.com/zhiwei1988/learning-audio/issues/7)。方法三层骨架的末端执行件（骨架见 CONTEXT.md「推导骨架」节，回验骨架见 `coupling-inventory.md`）。**两处调用同一程序**：双讲结算撞不上意图下限（物理冲突）、末端全量结算出现负余量墙（资源冲突）。

## 程序五步

1. **全量结算**：所有墙一次算完，先撞的墙 = 余量最小者——每轮的**输出**，不是假设。程序对「哪面墙先撞」零假设（L10「先撞内存不是算力」是一个 TI 样本，不推广也不需要推广——墙随输入迁移，零假设正是对迁移免疫的原因）
2. **吃无痛行**：耦合清单同赚行（#17 喇叭灵敏度/腔体选型、#18 出音孔面积），一次性收割，不算退让
3. **选动作**：②移墙——准入 = 代价落在有余量的墙上（由重结算判定，不是原则之争）；不准入则 ③退意图——退让顺序里第一个未触地的维度降一档
4. **重结算**：回到 1 重问先撞的墙。移墙动作先**显式反写平台约束册**再重跑（「每改一个输入都重问先撞哪面墙」在程序内也成立）。循环内**单向棘轮**——退了不回头
5. **停机**：可行 → 单遍赎回扫描 → 输出三件；全部可退维度触地仍不可行 → 输出**无解**

## 墙清单（默认五面，机型可增删）

算力（**峰值不按平均**）、内存、功耗、BOM、结构/腔体。机型可增：EMC、散热。

## 三类动作

| 类 | 动作 | 规则 |
|---|---|---|
| ① 无痛 | 吃同赚行 | 多本账同赚不算退让，程序第一步先吃 |
| ② 移墙 | 选项库的一次性架构决策，或耦合清单中代价落在资源墙的旋钮（#21 跨电压频率档、#17 换喇叭、#19 供电电压） | 准入 = 代价落在有余量的墙上；**无免费行**——写不出代价的选项不准入库；执行前显式反写平台约束册 |
| ③ 退意图 | 退让顺序第一个未触地维度降一档 | 原子步 = 降一档（档 = 字典档或目标/保底台阶——意图维度取值域必须离散成档，不存在连续微调）；**只动目标档，保底档即地板**；目标退到与保底重合，条款退化为单一门槛（#6 模板允许） |

②先于③的理由：方法服务产品竞争力决策，预算内花钱保竞争力优先于砍竞争力；②撑爆代价墙时自动不准入，自然落到③。

## 选项库（移墙的一次性架构决策）

| 选项 | 救哪面墙 | 代价落哪面墙 | 一次性/可逆 | 出处 |
|---|---|---|---|---|
| 协处理器（独立 DSP/NPU） | 算力、内存 | BOM、板面积、功耗 | 一次性 | coupling-inventory 清单外说明 |
| 借主 SoC 空闲算力 | 算力 | 与视频/ISP 的**峰值**冲突风险（按峰值重结算，不看平均） | 一次性 | 第 10 课「按峰值配」 |
| 换 SoC / 内存档位 | 算力、内存 | BOM | 一次性 | 第 10 课 |
| ONVIF backchannel → 私有协议 | 编码时延账（松绑编码枚举，可上 AAC-LD/Opus） | 生态兼容性 | 一次性 | coupling-inventory 清单外说明 |

## 赎回规则

循环内不赎回（棘轮）。可行停机后**单遍扫描**：按退让顺序从**最不愿退**的已退维度开始，试升一档 + 全量重结算——撑得住保留，撑不住回退；每维度只试一次，扫完即终止，不开第二轮循环。退让过程中耦合松动白捡的余量（如退放音音量 → THD 降 → ERLE 天花板松）由这一遍收割。

## 停机保证

同赚行有限（2 行）+ 选项库每项至多用一次 + 每维度档位有限且棘轮不回头 + 赎回单遍 ⇒ 程序必然停机。

## 输出

- **条款档位更新**：退掉的维度按新档改写条款（只动目标档）
- **退让台账**：进规格文档附录（表现层归「规格文档排版」雾）
- **平台约束册修订**：移墙动作的显式反写
- **无解**：合法输出——宣告该场景参数向量 × 平台约束不成立，这是立项期最有价值的结论之一（花钱之前知道不成立）。后续动作（换平台/重拍场景/砍功能/调价）是**重开入口向量**的立项级决策，回到人的桌上，程序不越权
