# 音质条款的挂靠：判据列 + 方向归组，可懂度不立维度

「拾音规格」曾被默认等同于「拾音距离」——8 条条款 4 条纯距离，P.1100 §11 十二个条目只投影了三个（工单 #15 的结构性缺口）。定案分三刀：**可懂度与证据用途不立音质维度**——它们是每个距离档的推导前提，落为分层承诺表新增的「判据」列（语音档取三级判据阶梯：检出/逐字/辨识；提示音档取听得见/分得清两级），从此「8 m」承诺的是哪一级不再靠猜；**与距离无关的音质走四个意图维度**（说话自然度/安静干净度/大声不破音/放音音色，纯用户措辞、无 dB，取值域三档，`reference/quality-dictionary.md` 落盘）；**音质条款按方向归组**——「拾音组·音质」「放音组·音质」两节与双讲组平级，条款仍套 #6 档×值模板且档槽为空，模板不扩槽。选档、地板、判据配级、退让序号归意图册（用户）拍板，方法只交取值域与刻度。

## Considered Options

- **可懂度立独立音质维度**：同一个「能听懂」会在距离档与音质维度两处承诺，两处可各自退让必然漂移；且可懂度天然绑距离（8 m 检出、1.5 m 逐字），脱离距离的「可懂度档」无法验收。否决——判据是距离档定义的缺失部分，不是新维度。
- **音质塞进分层承诺表／扩条款模板槽位**：分层承诺表的行必须是「同一功能按条件分档」（#6），自噪声、频响、削波不按距离分档，硬塞破坏表义；扩槽则所有既有条款陪着改。否决。
- **单独第三张「音质表」拾音放音混排**：丢方向信息——投影提问清单与分解测法时都要按方向拆回，等于把一次拆分成本摊给每个下游。否决。
- **每个距离档单挂一条质量条款**：一档拆成距离、质量两条互相引用的条款，评审桌上来回翻。否决——判据作列进档定义，一行读完。
- **方法侧代拍目标档/地板/退让序号**：2026-08-11 用户裁定这是产品价值判断，不归方法。否决——字典给选项，选档权归意图册；样张相应槽位如实标「待拍板」。

## Consequences

- 样张与空白模板改版（`spec-sheet-template.html`）：分层承诺表 +「判据」列；新增拾音/放音两个音质节；待拍板槽显式留空，不编数
- 意图册新增四个音质维度，取值域高/中/低三档；`quality-dictionary.md` 与 duplex-dictionary 同级，为方法固定资产
- 判据阶梯①③级与「分得清类型」「闷/尖对照」「P.835 可感知差距」五处刻度疑似空白 → research #27 核查；目标值与测法逐条定稿 → grilling #28（被 #27 阻塞），合订本 #24 改为被 #28 阻塞
- 耦合清单的音质账本（NS 强度、采样率、编码等行）有了条款级消费方，符号列重扫另立工单
- CONTEXT.md 新增「音质意图」节八词条
