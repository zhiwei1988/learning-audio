# 不可测条款走四出路程序，双讲测法双轨制

条款没有测法就只是漂亮话，但立项期不少条款当下测不了——双讲组尤甚（ERL/ERLE 低成本测量手册缺失，手工对齐误差 3–5 dB 大于 P.340 档宽 3 dB）。定案：每条条款标**测法等级**（能自测/需实验室/暂不可测），由**可复现性三问**推导（口径钉得死吗、工具链可负担吗、误差棒小于要判定的量吗——第三问是灵魂）；测不了的条款按**四出路**按序处理：差值化 → 转举证 → 参考期望 → 删（删仅当无任何决策用到这个数）；双讲组走**双轨测法**——内部轨用自推导近似只做排序与回归，对外轨转举证或第三方实验室。绝对值/差值按量的族分：物理量族写绝对值（有绝对标定的仪器，口径钉死即可复现），感知/算法量族一律差值（同场、同素材、成对），基线用同机 bypass 或同场竞品——「立项期没有基线」不成立，不需要历史基线。

## Considered Options

- **三出路原案（改写近似/参考期望/删）**：缺「转举证」。RESOURCES 已有先例（尾长-MIPS 曲线要三个点、Smart Amp 表征结果、THD 随电平曲线），且举证条款是「向方案商提问清单」的原生素材。补为四出路。
- **先补 ERL/ERLE 低成本测法手册再交付方法**：手册不阻塞任何决策（双轨制已把决策解锁），立为独立 task 工单择期做，不挡方法交付。
- **双讲条款整组降级为参考期望**：双讲是三组规格之一，整组降级等于方法交付缺一条腿。否决。
- **按设备清单定可测性**：违背第 8 课核心——消声室买的是可复现性，不是某台设备；改用可复现性三问，「能自测」的真义是误差棒小于要判定的差异，不是能得出一个数。

## Consequences

- 前提验证状态字段（#6 移交）就此定案：前提行四件套「前提｜验证状态（待验证/已验证/已证伪）｜最早可验证时机（立项期当下/等样机/等方案商）｜执行方（自测/方案商举证/第三方实验室）」；**已证伪 → 进退让程序**，程序本身归退让程序工单（#7）
- 测法槽位两级结构：规格表内一格只放「测法等级 + 判定形式（绝对值/差值@基线）+ 测法卡指针」，完整测法卡（口径、工具链、流程、典型误差棒与重复次数、执行方）扩进 `reference/measurement-cheatsheet.html`，不另起新文件
- 内部轨结果在交叉标定完成前不得写进对外文件——RESOURCES Gaps 的既有红线升级为方法规则
