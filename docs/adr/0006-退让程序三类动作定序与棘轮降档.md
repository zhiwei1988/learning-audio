# 退让程序：三类动作定序与维度级棘轮降档

推导必然撞墙（工单 #7；#3 已定两处调用同一程序、唯一让步依据是退让顺序）。定案：程序是**可执行五步循环**——全量结算定先撞的墙 → 吃同赚行（①无痛）→ ②移墙（准入 = 代价落在有余量的墙上）→ ③退意图（退让顺序第一个未触地维度降一档）→ 重结算重问先撞的墙；循环内单向棘轮，可行后单遍赎回，**必然停机**（同赚行有限 + 选项库单次 + 档位棘轮 + 赎回单遍）。**地板 = 带前提承诺的保底档**（无保底维度显式标注）；全触地仍不可行输出**无解**——合法输出，立项级结论，后续是重开入口向量的人的决策。

## Considered Options

- **加权多目标优化/评分权衡**：权重无外部依据（#9 红线：自定数不合法），结果不可解释，不保证停机。否决——权重这个东西方法里已经有了，就是意图册的退让顺序（#13 的多家对比同理不造评分表）。
- **连续微调意图（退 0.5 m、退 2 dB）**：用户观察不到 4.7 m 与 5 m 的区别——可感知的档才是意图的合法刻度；连续退让在「每次退一点点」里振荡不停机。否决——意图维度取值域强制离散成档（字典档或目标/保底台阶）。
- **固定验墙顺序（如「先验内存」）**：L10「先撞内存不是算力」是一个 TI 样本，不可推广；本图三次改输入墙三次换位。否决——程序对「哪面先撞」零假设，每轮全量结算取最小余量，这正是对墙迁移免疫的原因。
- **退意图先于移墙（先砍产品省钱）**：方法服务产品竞争力决策，预算内花钱保竞争力优先于砍竞争力；且②的准入由重结算判定（代价撑爆墙自动不准入落到③），②③之争不需要原则，只需要结算。否决。
- **自由赎回（退A松了B随时买回）**：振荡。否决——循环内棘轮，可行后按退让顺序从最不愿退的开始单遍扫描，每维度一次。

## Consequences

- 产品意图册每条维度新增两字段：**退让序号**（维度级全序，组级分辨不出「先退距离还是先退插话效果」）与**地板档**（缺省 = 保底档）；CONTEXT「退让顺序」词条随之升级
- **移墙必须显式反写平台约束册**再重跑结算——入口向量的显式修订，不是暗改；选项库无免费行，写不出代价的选项不准入库
- 退让只动目标档，保底档不可动；目标退到与保底重合，条款退化为单一门槛（#6 模板本来允许）
- 程序五步 + 台账模板 + 选项库落 `reference/retreat-program.md`（与耦合清单同级的方法固定资产）；台账进规格附录，表现层归「规格文档排版」雾
- 消费方：#13 多家对比 = 逐条判定 × 退让顺序；#8 已证伪前提从入口进程序；「无解」给立项桌「该场景 × 该平台不成立」的提前警报
