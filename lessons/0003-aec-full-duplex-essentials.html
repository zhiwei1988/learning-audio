Lesson 0003 · 约 22 分钟

AEC：全双工为何离不开它

把「有回音」从模糊投诉，翻译成可验收的问题：参考信号、声学耦合、残差抑制，以及半双工妥协。

与 Mission 的关系
「对讲自然」几乎总等于全双工。全双工成立的前提不是更好的麦，而是可靠的 AEC。你要能在评审里说清：回声来自物理闭环，算法靠什么消它，喇叭开大为何会拖垮它。

本课技能

听到一条对讲投诉或卖点时，能判断是否主要是 AEC 问题，并指出应先查的三个杠杆：参考路径、麦–喇叭耦合、是否退化成半双工。

回声不是噪声，是「已知信号的回灌」

全双工时，远端话音经喇叭播出，再被本机麦克风拾起，送回远端——对方听到延迟的自己。 ADI 把这条路径拆成两条并行支路： 声学路径（功放 → 喇叭 → 房间 → 麦克风）与 DSP 路径（用同一段播放信号做估计）。 （ ADI · Acoustic Echo Cancellation ）

TI 面向门铃 / IP 摄像机的参考设计 TIDA-01589 说得同样直白：免提全双工时，喇叭能量耦合进麦克风，再叠加环境噪声，会严重损害可懂度——必须做噪声抑制与声学回声消除。

Far-end

远端话音（参考）

即将从喇叭播出的数字信号。AEC 必须拿到这份 reference，否则无法建模「自己刚播了什么」。

产品坑：参考取错时钟域、延迟未对齐、音量曲线与真实功放不一致
Acoustic

喇叭 → 结构 → 房间 → 麦

真实回声路径：直达漏音 + 腔体/外壳耦合 + 房间反射。路径越强、非线性越大，AEC 越难。

竞争力：麦喇叭隔离、防水膜、喇叭限幅；投诉：开大音量就回音
AEC

自适应滤波 + 残差处理

用参考估计回声并相减（线性部分）；残余非线性常用 RES / NLP 再压。可选再接 NS。

卖点：全双工、自然对讲 · 失败：回音、断续、双讲卡顿
Near-end

希望只留下本端说话人

理想输出：现场人声；远端回声被消掉。本端说话时滤波器应暂停或减慢学习（双讲保护）。

投诉：双方同时说话时一方被削掉 / 「像半双工」

三个必须钉死的概念

1. Reference —— AEC 与 NS 的分水岭

AEC 消的是已知播放信号经声学路径回来的成分。 NS / ANR 抑制的是环境噪声（空调、风、马路），通常没有播放参考。 评审时一句话：有参考 → 先谈 AEC；只是「吵」→ 先谈 NS / 结构 / SNR。

决策含义 「开了 AI 降噪」不能替代 AEC。降噪再强，也可能把回声当成「要保留的语音」或留下怪异伪影；全双工仍需要参考驱动的回声消除。

2. 自适应滤波 —— 在学「房间+喇叭」的冲激响应

ADI 实现以自适应 FIR 建模声学路径，再从麦信号中减去估计回声；线性部分消不干净时，用残差块（RES / NLP）处理非线性伪影，并常与噪声抑制串联。 FIR（Finite Impulse Response，有限冲激响应）= 只用过去有限个输入采样做加权求和的滤波器；AEC 线性部分用一排可调 taps 去拟合喇叭→麦路径，长度决定能盖住多长的 echo tail。

回声尾长（echo tail）是什么

喇叭响一下之后，麦克风里听到的不只是「当下那一拍」，而是一串延迟叠在一起的副本：壳体内直达耦合、腔体/结构振动、门口墙面反射、更远的多次反射。 从「喇叭发出」到「麦里回声能量低到可以忽略」的这段拖尾时长，就是 echo tail（回声尾长）。 它不是「有没有回声」本身，而是回声在时间轴上拖多长。

AEC 的自适应滤波器在学这条路径的冲激响应。滤波器有多长（多少个 taps），就只能「记住」多长的拖尾。 tap（抽头）= 滤波器里一个延迟点上的可调系数：把「过去第 i 个采样」乘上权重 wi 再累加，得到估计回声。 N taps = N 个系数 = 覆盖过去 N 个采样；除以采样率 fs 就是可建模的秒数：

可覆盖尾长 ≈ N taps ÷ fs  →  例如 640 taps ÷ 16 000 Hz ≈ 40 ms

课里常见量级：ADI 默认 640 taps @16 kHz ≈ 40 ms；TI TIDA-01589 的 DSP AEC 宣称可处理至约 128 ms——数字越大通常算力与时延预算越高。

情况 结果
尾长预算 ≥ 真实拖尾 线性部分能把主要回声减掉，残差压力小
尾长预算 < 真实拖尾 后面的反射消不掉 → 远处还「嗡」一点的残余回声
尾长预算过长 多出来的 taps 易学噪声/本端话；算力与时延预算上升

为何同一台机贴墙往往比自由场尾更长

自由场（悬空、周围空旷）时，麦主要听到壳内/结构直达耦合和外壳上的短路径散射；远处没有强反射面，h(t) 前几毫秒很高、后面掉得快 → 有效尾长短。

贴墙等于在喇叭–麦路径旁加了一块强反射面：声能打到墙再弹回麦，多走一段往返路程，到达更晚；硬墙（瓷砖、水泥、玻璃）吸收小，反射仍够强，再叠加门框/地面的多次反射，冲激响应中后段多出一截拖尾。 用镜像声源想：墙后相当于有一个「虚喇叭」，路径差大约是机–墙距离量级的两倍。

这与「音量开大」要分开看：开大主要加强早期能量与喇叭非线性；贴墙主要加长晚到反射。软墙、远距离贴装时尾长增加可不明显——所以说「往往」，不是铁律。

回声尾长怎么测

工程上就是量（或估）本机喇叭 → 本机麦路径的冲激响应：能量从峰值衰减到「可以当它没了」要多久。 阈值要写进评测规范（常见：峰值下 −40 dB 粗算主拖尾；−60 dB 更严；或落到本底噪声）。

方法 怎么做 何时用
扫频 / 反卷积（首选） 关 AEC·NS·AGC，喇叭播指数扫频（或 MLS），录 raw 麦，反卷积得 h[n]；从直达峰到持续低于阈值的时间 = 尾长 可复现的选型与结构对比
互相关粗测 播已知参考，算 ref 与麦的互相关；最后一个明显高于噪声底的峰的时延 ≈ 尾长量级 快速判断 40 ms 还是 100 ms+
收敛后的 FIR 系数 远端单讲、近端静，等 AEC 收敛后看 wi；最后一个仍显著的系数序号 ÷ fs 算法在机上时，看预算是否用满/浪费
加长 taps 看残余 / ERLE 固定场景逐步加长滤波器；ERLE 不再明显上升的拐点 ≈ 够用尾长 黑盒验收、栈只给配置项时

最小可复现：bypass 算法 → 本机扫频 + raw 麦 → 反卷积画 h(t) → 按约定阈值读时间。 必测矩阵：音量档位 × 安装面（贴硬墙 / 门框 / 开阔）。 选型回扣公式：所需 taps ≳ 测得尾长 × fs（再留余量，例如 1.2～1.5×）。 例：50 ms @16 kHz → 至少约 800 taps。

别混 房间 RT60 会把尾长拉长，但 RT60 ≠ 机内耦合尾长；规格书上的 40/128 ms 是算法能覆盖的预算，不是你测到的真实拖尾。整机 mouth-to-ear 时延是另一回事。
但两者有一条硬耦合：播放缓冲 + 空气路径 + 采集缓冲 必须小于尾长，否则回声整段跑出滤波器覆盖范围，AEC 完全失效。 见 第 6 课 · 时延预算。

摄像机含义： 门口硬墙、走廊空旷会加长拖尾；塑料壳内强耦合、大音量喇叭会加强前几毫秒的能量（尾长未必更长，但更难消）。 结构改动（换喇叭、改密封）= 路径变了 = AEC 要重新收敛；量产评测要覆盖「音量档位 × 安装表面」——桌面悬空测「够了」不等于贴墙也够。

喇叭–麦布局：用 ERL / 隔离 dB 说话，不只报毫米

喇叭与麦的距离、开孔朝向、是否共腔，首先改变的是耦合强弱，其次才是路径时延与尾形。 毫米是结构设计输入；对 AEC 验收应落到可测指标：

指标 含义 布局变差时
隔离 dB 喇叭侧电平 − 麦侧电平（耦合有多弱） 距离近 / 共腔 → 隔离下降
ERL（Echo Return Loss） 回声路径回损：播出相对「又被麦捡回」衰了多少 ERL 下降；免提大音量可为负值
h(t) 主峰 / 尾长 直达强度与拖尾时长 主峰升高；贴墙还常加长尾
ERLE AEC 额外压掉多少 dB（算法，不是结构） 耦合过强时 ERLE 难做高，更依赖 NLP
残余回声 / 双讲 / 收敛 消完后听感与稳定性 残余↑、双讲更脆、收敛变慢

因果链：布局/距离 → 隔离与 ERL 变差 → 线性 FIR 残差变大 → NLP 更猛或全双工垮掉。 大音量还会叠非线性与削波，不只是「距离」一个数。

ERL 与隔离：定义与典型量级

隔离 dB：只有喇叭在响时，喇叭侧电平减去麦侧电平。越大 = 耦合越弱。 ERL：近端静、AEC 关时， ERL ≈ LRout − LSin （播放参考 / receive-out 相对上行麦上的回声）。越大越好；为负表示回声比参考还「凶」。

当 Rout 就是 AEC 参考、Sin 就是 raw mic、单位与带宽一致时，数字通路上的隔离与 ERL 往往是同一测量、两个名字。 声学两点法（声级计在喇叭前与拾音孔）得到的是声学隔离，和数字 ERL 差一条电声与增益链，横比时不要混。

行业没有门铃/枪机统一国标数。电话与免提文献 + 紧凑全双工工程经验，可作评审锚点（同音量、同带宽、AEC 关）：

档位（结构） 数字 ERL / 隔离（约） 对 AEC 的含义
差：共腔、孔对孔、大音量驱离 约 −12～+5 dB（负值常见） 线性部分吃力；NLP 易开狠或退化半双工。文献中免提 ERL 差到 −12 dB 并不罕见
可干活：有基本分腔/密封 约 +6～+15 dB 与线路 hybrid「ERL ≳ 6 dB」同一量级锚点；全双工靠扎实 AEC 可做
好结构：分腔、减振、开孔错位 约 +15～+30 dB（中语音带） 线性 FIR 压力明显下降；双讲余量更好
优秀 / 大间距手持听筒类 约 +30 dB 以上 AEC 轻松；紧凑门铃/枪机很少到此档
读数纪律 量级随音量、EQ、限幅、带宽、计权、安装面剧变——报告必须写清条件。 最大驱离档「差一截」往往可接受，但不能用对讲默认档的漂亮数代替大音量验收。 线性 ERLE 约 20–30 dB、总衰减到 ~40 dB 量级常被说成「听感接近干净」——那是算法指标，别和结构 ERL 比大小。

ERL / 隔离怎么测

共同前提：关 AEC·NS·AGC（量结构不是量算法）；近端静；音量档与安装面写死；带宽统一（如 300–3400 Hz 或 100 Hz–8 kHz）；计权要么都不用要么都 A 计权；激励用粉噪数秒或扫频，勿削波。

隔离 dB ERL
测点 A 喇叭侧：数字参考（与功放一致）或约定声学点 SPL Rout / 播放参考（receive-out）
测点 B 麦侧：raw mic 数字电平或拾音孔 SPL Sin 上行麦（近端静 ≈ 纯回声）
计算 LA − LB（同带宽功率） LRout − LSin
首选做法 数字通路：同步抓 reference + raw mic → 稳态段功率相减（结构评审与 AEC 对齐）
结构辅证 声学法：声级计喇叭约定点 − 拾音孔 一般不单独用声学两点冒充电话 ERL

最小脚本： ① 算法全关，音量=对讲默认，贴墙； ② 播 8 s 粉噪，录 reference + raw mic； ③ 取中间稳态：ERL = dBFS(ref) − dBFS(mic)； ④ 再测最大驱离音量、自由架空； ⑤ 重要改版加看 ERL(f)（分频带），避免壳体共振峰被全带平均数掩盖。

常见坑 参考不是真功放路径（EQ/限幅后才到喇叭）→ 数虚高，AEC 仍对不齐； 麦削波 → 功率乱； AEC 开着测 → 当成结构指标会美化； 把 ERL 和 ERLE 比大小 → 无意义（一个硬件、一个算法）。

3. Double-talk —— 全双工最难的一档

双方同时说话时，麦里混着本端语音 + 远端回声。若滤波器继续猛学，会把本端语音当成回声「学进去」而损伤语音。 ADI 明确：检测到声学路径中出现与 far-end 无关的声音时，滤波器应暂停适应，以便本端话音能送到远端。

产品听感： 双讲时一方突然变轻、断续、像对讲机抢麦——常见是双讲检测过猛，或其实整机在半双工策略下用 VAD 互斥。 「全双工」卖点要用双讲用例验收，不能只测单人轮流说。

失败模式 → 你该查什么

听感 / 投诉 优先怀疑 产品杠杆
听到自己延迟回来 AEC 未工作 / 参考缺失或延迟错 核对 reference 路由与 delay；是否半双工伪装
小声还行，喇叭开大就回 路径非线性（喇叭 THD）、残差抑制不够 限 SPL、Smart Amp 保护、加强隔离、调 NLP
双方同时说就断 双讲检测过激 / 实为半双工 双讲用例评测；核对是否 VAD 互斥
消回声后「空」或沙沙 NLP 过猛切信号；缺舒适噪声 残差参数；comfort noise（若栈支持）
只有环境吵、无自我回声 多半不是 AEC，是 NS / SNR / 远场 回到第 1–2 课：声场、麦 SNR、降噪
常见误区 「换更高 SNR 的麦就能解决回音」。麦 SNR 改善底噪与远场，不消回声闭环。回音要靠 AEC + 声学隔离；有时换麦（灵敏度/相位）反而改变路径，需要重调。

竞争力评审三问

  1. 是全双工还是半双工？ 半双工用互斥掩盖回声，体验上限低，但实现便宜——写进规格，别用「自然对讲」糊弄。
  2. 参考是否可信？ 播放链路的音量、EQ、限幅是否与 AEC 看到的 reference 一致？不一致 = 估计永远对不齐。
  3. 喇叭竞争力是否在吃 AEC？ 「更大声驱离」会恶化耦合与非线性；要同时预算隔离 / ERL 与尾长/算力，而不是只加功放。改布局先对比默认音量与最大音量下的 ERL，再谈算法参数。
