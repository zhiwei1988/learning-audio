三个回声数，自己测：ERL / ERLE / 双讲衰减

第 3 课给了 dBFS 相减的思路，第 8 课给了可复现性的框架，但两边一直没合成一份可照做的流程——而且手工对齐的误差比要判定的档宽还大。这一课把流程合上、把对齐交给脚本，并且回答最关键的一问：这套自制近似，凭什么可信？

与 Mission 的关系
双讲条款（ERLE、P.340 等级）目前的测法等级是「暂不可测」——不是没有思路，是误差棒大于要判定的量。 本手册的目标就是把误差棒压进 3 dB 档宽以内，让双讲条款对内升级为「能自测」； 对外声称仍走举证或第三方实验室，这条红线本课最后一节会再钉一次。

本课技能

给你一台在手样机，不花钱跑出 ERL、ERLE、双讲衰减量三个数， 每个数带条件行与波动范围；并能说清哪个数已有同行印证、哪个还是自制近似、离「能写进对外文件」还差哪一步。

一、三个数、三本账——先分清谁是谁

三个数都叫「回声相关」，但记在三本不同的账上。前课都讲过（第 3 课、第 8 课），按间隔重复的惯例重述一遍再用：

量它是什么记在哪本账参照什么读
ERL
Echo Return Loss · 回声返回损耗		 喇叭放出去的声音回到自家麦上时损失了多少——算法全关时量的结构耦合 结构账（腔体、布局、密封） 第 3 课档位表：+6～+15 dB 算「可干活」，负值常见于共腔大音量
ERLE
Echo Return Loss Enhancement · 回声消除增益		 AEC 在 ERL 之外额外消掉多少回声——算法指标 算法账（尾长、收敛、非线性） 20–30 dB 是免提行业「好用户体验」锚点（Microchip）；上限被喇叭 THD 锁死（第 9 课：≤ −20·log₁₀(THD)）
双讲衰减量 aH,S,DT
attenuation during double-talk		 对方也在说话时，你的声音被额外压掉多少——整机行为指标 行为账（双讲策略、NLP） P.340 分级：≤3 dB 全双工，>12 dB 实为半双工（3 dB 一档）
老规矩 三个数不许互比大小（第 3 课讲过：一个硬件、一个算法、一个行为）。 也不许混着报——报告里每个数前面写清是哪一个，后面写清测量条件。

二、内部轨凭什么可信：同行印证到哪一步了

我们的内部轨是「dBFS 相减 + 声学环回」的自制近似。查证结果：其中 ERLE 的算法有一手同行印证，双讲衰减的流程仍是自制——两者可信度不同，要拆开说。

Microsoft 的 ICASSP 2021 AEC Challenge（在 2500+ 台真实设备的录音上评测回声消除）用的 ERLE 定义正是能量比：

「ERLE ≈ 10 log₁₀ ( E[y²(n)] / E[e²(n)] )，其中 y(n) 是麦克风信号，e(n) 是消除后的残余回声。 ERLE is only appropriate when measured in a quiet room with no background noise and only for single talk scenarios (not double talk).」 —— ICASSP 2021 AEC Challenge 论文 §1，公式出处标注为 ITU-T G.168 与 Enzner 等《Acoustic Echo Control》

两个功率取对数再相减，就是两个 dBFS 电平相减——我们的做法与文献同构。同一篇论文也把边界钉死了： ERLE 只在安静房间 + 远端单讲下有意义，且与主观听感分数相关性低（他们实测 Pearson 相关只有 0.3 上下）—— 所以它只能用来排序与回归，不能用来声称「听感好」。这恰好就是双轨测法给内部轨划的射程，现在有了一手出处。

内部轨组成可信度现状还差什么
ERLE = 能量比（dBFS 相减） 已有同行印证：G.168 定义、AEC Challenge 在真实设备录音上沿用 无——在「安静房间 + 远端单讲 + 只做排序回归」边界内可放心用
双讲衰减 aH,S,DT 的喇叭+录音笔流程 仍是依据 P.340 定义自行推导的近似，未见等价公开流程；AEC Challenge 在双讲段干脆放弃客观指标、改用主观听音 交叉标定（本课第七节）；完成前不得写进对外文件

三、开测前：把口径钉死

第 8 课的可复现性三问，第一问就是「口径钉得死吗」。下面每一行开测前写进记录，测完随数报出——少一行，这场数据就和下一场比不了：

要钉死的口径怎么钉
算法开关状态测 ERL：AEC / NS / AGC 全关；测 ERLE：只开 AEC，NS / AGC 关；测 aH,S,DT：全开（量的就是整机行为）
音量档对讲默认档一组，最大驱离档一组，分开报——第 3 课讲过：不能用默认档的漂亮数代替大音量验收
安装面贴墙 / 自由架空，写死并拍照；换安装面 = 新的一场
几何「本地说话人」喇叭在被测机正前方 0.5 m、约 65 dB SPL——直接抄 P.340 的 HFRP 条件，省掉自己定标准
录音增益基准参照录完后从此不许动（第 8 课配对四规则）
采样率 / 带宽全链统一（如 16 kHz / 100 Hz–8 kHz）；不一致先重采样，脚本会拒绝采样率不同的输入
素材P.501 测试语音（ITU 电子附件免费）；同一场内素材逐字节不变
房间底噪开测前测并记录 dB(A)（REW + UMIK-1 或声级计）；装修队开工的日子不测

四、流程 A：ERL（结构账）

升级自第 3 课的最小脚本，加上了重复与报数格式：

步骤做什么为什么
1算法全关，音量 = 对讲默认档，按口径表布好量结构，不量算法
2播 8 s 粉红噪声，同步抓播放参考（送功放那一路）与 raw mic参考必须取自真实功放路径（EQ / 限幅之后），否则数虚高且 AEC 对不齐
3取中间 4 s 稳态窗，ERL = dBFS(参考) − dBFS(raw mic)两个数字域电平一步相减，无隐藏换算
4重复 5 次，报中位数 + 极差粉噪稳态下抖动很小，5 次足够暴露异常场
5切最大驱离档再来一轮；重要改版加测分频带 ERL(f)壳体共振峰会被全带平均数掩盖（第 3 课）

读数标尺沿用第 3 课档位表：+6～+15 dB 可干活，+15～+30 dB 好结构；改结构（分腔、密封、出音孔错位）的收益直接从这个数上看。

五、流程 B：ERLE（算法账）

基线用同机 bypass（测法绑定定案：感知/算法族一律差值，基线 = 同机 bypass）——同一台机器、同一场，AEC 开 / 关各录一次：

步骤做什么为什么
1场景：远端单讲——远端播 P.501 语音，本地全程无人说话，房间安静ERLE 只在这个边界内有意义（AEC Challenge 原句，见第二节）
2AEC bypass，在送出端（send output）录残余 → 这就是「消除前」同机 bypass 基线；没有 bypass 开关就录 raw mic，并在条件行写明取点不同
3AEC 开，同素材再录一次 → 「消除后」唯一变量是 AEC 开关
4用对齐脚本在两段录音里截同一句话（用法见第六节），各算 dBFS不同句子本身响度不同，那是新变量
5ERLE = dBFS(bypass 窗) − dBFS(AEC on 窗)；换 3 个不同窗各算一次，报中位数 + 极差一步相减；多窗防止刚好选中收敛前的段落
6把窗挪到录音前 2 s 单独算一个数，标注「收敛期」AEC Challenge 的远端单讲素材特意放两遍，就是为了把「收敛中」和「收敛后」分开看
读数标尺 收敛后 20–30 dB 摸到免提行业「好体验」锚点；顶不上去先查喇叭 THD 天花板（第 9 课：ERLE ≤ −20·log₁₀(THD)，10 % THD 就是 20 dB 封顶），再怪算法。 收敛期明显低于稳态属正常，两个数分开报即可。

六、流程 C：双讲衰减 aH,S,DT（行为账）——对齐交给脚本

流程沿用第 8 课六步（本地喇叭单讲录一次、加远端素材双讲录一次、同一句相减查表）。 过去卡脖子的是第 5 步「截出同一句话」：手工对齐的窗口错位估计带来 3–5 dB 误差（经验值，未系统实测），而 P.340 一档只有 3 dB——误差棒比要判定的量还大，这正是双讲条款「暂不可测」的直接原因。

现在这一步交给 assets/align-dt.mjs（零依赖，node 直接跑）：它用互相关找到参考素材在每段录音里的样本级偏移，同一参考窗在两段录音里各截一刀，RMS 相减： 

node assets/align-dt.mjs 参考素材.wav 单讲录音.wav 双讲录音.wav --window 0.5,2.5

单讲窗电平  -16.78 dBFS（偏移 5000 样本）
双讲窗电平  -24.24 dBFS（偏移 11000 样本）
a_H,S,DT = 7.47 dB（查 P.340 表定档；本数仅供同场成对比较）

自检（合成数据）：植入已知 7.5 dB 压制 + 底噪，脚本测得 7.47 dB、偏移样本级命中——对齐这一项的误差从「手工 3–5 dB」压到 0.1 dB 以内。 测试套件在 assets/align-dt.test.mjs（node --test），改脚本前先跑绿。

误差账现在长这样——哪项多大、谁除得动，一目了然：

误差项量级怎么压
窗口错位（手工对齐）3–5 dB（经验值，标注待实测）脚本对齐后 ≤0.1 dB（合成自检实测）——从账上划掉
单次抖动随素材与房间，配对测下按第 8 课公式：误差棒半宽 = 1.96 × 单次抖动 × √(2/次数)加次数除得动；先跑 5 次算出你自己的抖动值再定次数
场次偏置整场一起偏配对（同场、同素材、增益锁死）消掉；分开测有地板 1.96×√2×偏置，次数除不动

判定标准（可复现性三问的第三问）：误差棒 < 3 dB 档宽，测出的档位才算数； 误差棒跨档就老实报「介于 2a/2b，本次分不开」。

七、交叉标定：从「暂不可测」到「能自测」

红线重述：内部轨结果在交叉标定完成前不得写进对外文件。标定路径两条，一条已走完：

路径覆盖状态
同行印证 ERLE 能量比法 已完成（本课第二节：G.168 定义 + AEC Challenge 在真实设备录音上沿用 + 边界原文）
第三方实验室一次性标定 双讲衰减 aH,S,DT 流程 待执行：送一台样机按 P.340 §8 做双讲测试（消声室 + 人工嘴 + CSS 信号），同一台机、同一固件、同一音量档在内部轨复测；实验室值 − 内部轨值 = 定标偏移，多次差值的波动 = 内部轨对外误差棒

标定完成后：双讲条款测法等级对内升「能自测」（拿标定偏移修正后可判档）； 对外仍写举证或实验室报告——内部轨永远不出现在对外文件里，这不因标定而改变。 实验室送样是人工待办（选实验室、要报价、寄样机），清单在工单里。
