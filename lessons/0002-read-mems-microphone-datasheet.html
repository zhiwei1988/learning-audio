Lesson 0002 · 约 15 分钟

读 MEMS 麦克风 Datasheet

把 SNR、AOP、灵敏度从参数表翻译成产品决策：这颗麦适合远场听人声，还是扛门口大动态？

与 Mission 的关系
竞争力评审里，「换颗更好的麦」是最常被甩出来的方案。你会用 datasheet 判断：该砸在 SNR 上、AOP 上，还是其实麦已经够好、瓶颈在结构/算法/编码。

本课技能

给定使用场景 + 两行麦参数，选出更合理的一颗，并用 SNR / AOP / 灵敏度说明理由（而不是「数字更大」）。

先钉死测试锚点

麦克风灵敏度几乎总是用 1 kHz 正弦、94 dB SPL（1 Pa） 测出来的。 这是声学域与电气域的换算锚点——不是「日常说话有多响」。 来源： ADI · Understanding Microphone Sensitivity。

比较规则 两颗麦的 SNR 都写 65 dB，也要看脚注：是否 A 计权、测量带宽、模拟还是数字输出、供电模式。脚注不一致时，数字不可直接横比。

三个核心数字（按优先级）

1. SNR — 安静与远场的天花板

SNR = 94 dB SPL 参考信号 相对 麦克风自噪声 的比值（常见 A 计权，单位 dB(A)）。 等价地：

等效输入噪声 EIN ≈ 94 − SNR　（dB SPL）

例：SNR = 65 dB → EIN ≈ 29 dB SPL。比这更轻的声音，在理想条件下也会被自噪声淹没。 ADI 明确：跨模拟/数字接口时，应用声学域的 SNR 与最大声压来比较，而不是输出格式。

摄像机含义： 客厅/走廊远场、夜间安静环境要「听清轻声说话」——先看 SNR。 距离每翻倍约 −6 dB 声压（自由场），远场信号更弱，更容易掉进噪声底。 ADI 把 security cameras 列为需要认真对待远场衰减的场景之一。

2. AOP — 大声时炸不炸

AOP（Acoustic Overload Point）：失真达到约定阈值（常见 10% THD）时的声压级。 Infineon 选型指南把它列为与 SNR 并列的核心 datasheet 限值：安静靠 SNR，响亮靠 AOP。 （ Infineon · Factors to consider when choosing a MEMS microphone ）

摄像机含义： 门铃对讲大喊、关门砰、警报/驱离喇叭回灌到麦——需要高 AOP，否则「啪」一声失真，AEC 也会更难收敛。

3. 灵敏度 — 增益匹配，不是音质分

模拟麦：单位常为 dBV（相对 1 V）。数字麦：dBFS（相对数字满幅）。 数字麦灵敏度往往被最大声压锁死，例如最大 120 dB SPL → 灵敏度约 −26 dBFS（94 − 120）。

常见误区 「灵敏度更高 = 拾音更远/更好」。错。灵敏度只说明同一声压下输出有多大；质量更应看 SNR、动态范围、THD、电源抑制等。高灵敏度在近场还更容易先削波。

远场系统确实可能需要更高的系统增益，但那是整条链（预放/数字增益/AGC）的预算问题，不是单独把 datasheet 灵敏度拉满。 在 DSP 满幅已贴着麦的最大声压时，再加数字增益 = 等效降低削波点（AOP 被吃掉）。

动态范围：一眼公式

麦克风可用动态范围 ≈ 最大不失真声压 − 噪声底：

Dynamic range ≈ AOP − EIN ≈ AOP − (94 − SNR)

例（ADI 叙述同型）：最大约 120 dB SPL、SNR 61 dB → EIN 33 dB SPL → 动态范围约 87 dB。 系统最终听感还会被 ADC、算法、编码木桶卡住（第 1 课）。

动手：把 datasheet 三个数变成产品语言

场景对照：摄像机怎么选

室内云台 / 客厅监控

  • 目标：数米外人声可懂
  • 威胁：空调、冰箱、混响
  • 大动态事件相对少

优先：高 SNR → 再谈结构与 NS 算法

门铃 / 门口枪机

  • 目标：对讲清晰 + 事件声不炸
  • 威胁：喊叫、风、雨、关门
  • 常有喇叭近距离耦合

优先：足够 AOP + 可接受 SNR；结构隔离很关键

评审话术模板 「这颗麦 SNR xx dB → EIN 约 yy dB SPL；AOP zz dB SPL。我们场景是远场人声，瓶颈更像 SNR/结构而不是灵敏度。AOP 只要覆盖门口峰值即可，盲目追灵敏度会牺牲削波余量。」
