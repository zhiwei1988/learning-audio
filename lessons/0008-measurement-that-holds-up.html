Lesson 0008 · 约 20 分钟

没有消声室，也能测出结论

前七课每一课末尾都留了一串验收条款——「要求 X 米、Y dB(A) 下的 S-MOS」。但那些数，你自己怎么测？这一课回答它，并说清一件反直觉的事：你缺的从来不是精度，是可复现性。而可复现性可以不花钱买到。

与 Mission 的关系
MISSION 里写着「写出可验收的音频需求/评测条目」和「在跨职能评审中提出有证据的建议」。 前面七课给了你要什么数，这一课给你怎么拿到数——以及更重要的： 怎么判断一个数（你的，或供应商给的）能不能当证据。

本课技能

给定一个「A 和 B 哪个好」的问题，能设计一次你自己就能跑的测试， 算出它的最小可分辨差异，并说清结论能证明什么、不能证明什么。 顺带把第 3 课留下的那个空——「全双工要用双讲用例验收」——补成一个可以查表的等级。

一、先问你要回答哪个问题

二、消声室到底买的是什么

免提设备的测试条件写在 ITU-T P.340 里（免提终端的传输特性与语音质量参数）。 它对测试环境的第一句话，是整节课最值得读的一句：

标准自己说了实话 「For the repeatability of the tests, the environment for most of the measurements shall be free field (anechoic) down to the lowest frequency of the 1/3 octave band centred on 200 Hz.」 （ITU-T P.340 §5.4，可免费下载）

注意开头那半句：消声室是为了可复现（repeatability）—— 让同一台机器今天测和下个月测、在东京测和在深圳测，得到同一个数。 它买的不是「真实」，是「不变」。

这句话是本课的钥匙：如果我能用别的办法买到「不变」，我就不需要那间房。

那间房有多苛刻？P.340 §5.4 与 §5.3 的几条硬指标：

先说清楚一个单位 dBPa：以 1 帕斯卡（Pa）为 0 点的声压级刻度。 而 1 Pa 就是第 2 课那个 94 dB SPL。 所以换算只有一步：dB SPL = 94 + dBPa。 电话行业用它，是因为免提测试的电平天生都在 94 dB SPL 以下，写成负数比写 SPL 顺手。

两个来源、两条路径，落在同一个点上。这不是巧合，是「正常人说话」这件事只有一个答案—— 你之前算远场用的那把尺子，和 ITU 校准人工嘴用的是同一把。

还有一条常被忽略但很省事的：测试信号必须符合 ITU-T P.501（P.340 §5.5）。 而 P.501 的语音素材与噪声序列是免费公开下载的。 也就是说，四条要求里有一条你今天就能满足，而且零成本。

三、绝对分靠不住——这有实证

上一节是「标准说它需要可复现性」。这一节是「不满足条件时到底有多不可复现」——有人认真做过这个实验。

Naderi 与 Cutler 把 700 条同样的音频素材，用同一套流程、 在五个不同的日子各跑一次主观听音测试，每天换一批人（平均 89 位互不重复的评分者）。 唯一变的是「哪一天、哪批人」。结果：

先说清楚一个读数 ICC（组内相关系数）：同一件事重复做 N 次，N 次的结果彼此有多一致。 1.0 = 五次完全重合；0 = 五次之间毫无关系。
粗略标尺：0.9 以上可以拿来做决策；0.7 上下叫「勉强」—— 意思是你看到的差别里，有相当一部分只是「今天是星期几」。
看哪个数它是什么五次之间的一致性 ICC
MOS（绝对分） 「这段音频几分」——直接报出来的分 0.719　勉强
DMOS（差值） 「这段音频的分 减去 同一场里那段未处理原声的分」 0.907　可用

来源：Naderi & Cutler, An Open source Implementation of ITU-T Recommendation P.808 with Validation（INTERSPEECH 2020）§4.2。 原文：「bias observed between MOS values in different runs is a well-known and common behavior in the subjective tests. Using the DMOS successfully removed that offset.」 同一篇还验证了这套众包流程与实验室 P.800 结果的相关性 PCC = 0.962。

这张表在说什么 素材没变、流程没变、题目没变，只是换了一天，绝对分就整体漂移了。 但漂移是整场一起漂的——所以只要你在同一场里也测了一个参照物， 两者相减，漂移就消失了。

这就是那把不用花钱的钥匙：消声室用「把环境钉死」买可复现性，你用「减去同场的参照」买同一样东西。

而且这条规律不只对人耳打分成立。房间没变但空调开了、麦的位置挪了 2 cm、 功放热了 3 度、录音设备的增益旋钮被人碰过——每一样都是「今天是星期几」。
配对四规则 · 本课最该记住的东西
  • 同一场：A 和 B 在同一次开机、同一个房间、连续测完。绝不「今天测 A，明天测 B」。
  • 同一素材：用同一个音频文件由喇叭播出，不要真人说话——人是不可复现的声源。
  • 同一参照：每一场都测一次「不变的那个东西」（原始未处理录音、或一台从不改动的基准机）。它是你的零点。
  • 报差值：结论写「B 比 A 好 1.8 dB」，不写「B 得了 3.4 分」。绝对分只在同一场内部有意义。

四、那这个差值，是真的吗？

配对解决了「场次漂移」。但还剩一件事：就算在同一场里，同一台机器连测两次也不会给出同一个数。 于是你测到 B 比 A 好 0.4 dB——这 0.4 是真的，还是抖出来的？

三个词，一次说清 单次抖动：同一台机器、同一个条件，连测两次的差别有多大。这是你无法消除的随机成分。
场次偏置：整场一起偏的那个量（换了一天、挪了位置、动了增益）。配对能消掉它，重复测多少次都消不掉。
误差棒：你测到的那个差值，真值有 95% 的可能落在这段区间里。 只要这段区间跨过 0，你就不能说「B 比 A 好」——因为「一样好」也在区间里。
配对测（同场交替）：误差棒半宽 = 1.96 × 单次抖动 × √(2 / 次数)
分开测（A 今天 B 明天）：= 1.96 × √(2 × 场次偏置² + 2 × 单次抖动² / 次数)
注意第二个式子里，「次数」只除得动第二项。第一项是地板—— 加测再多次，误差棒也压不到 1.96 × √2 × 场次偏置 以下。

下面这个模拟器让你亲手撞一次这堵墙。它替你扮演「真值已知」的上帝视角——现实里你永远不知道真值， 这正是为什么你必须先算误差棒。按顺序试这四步：

  1. 默认就是分开测 · 真实差异 +0.5 dB · 抖动 ±0.5 · 偏置 ±1.5 · 各测 3 次。看结论。
  2. 连点五次「重新做一次这个实验」。真值一直是 +0.5，而「本次测到的差值」在 ±4 之间乱跳，有时还是负的。这就是不可复现长什么样。
  3. 把「各测几次」拉到 30 次。误差棒从 ±4.23 变成 ±4.17——十倍的工作量，几乎没变。盯住那行公式，看是哪一项没被除掉。
  4. 次数保持 30，只把设计切成配对测。误差棒 ±0.25，胜率从 3% 跳到 98%。一个字的改动，抵过十倍的工作量。
第 3 步是这一课最贵的一行 「多测几次」是错觉。它只压得住单次抖动，压不住场次偏置。 你把 3 次加到 30 次，误差棒从 ±4.23 挪到 ±4.17，然后宣布「看不出差别」—— 而真正的问题是这个测法本身有地板，你今天再测三百次也踩不穿。

要改的是设计，不是次数。这句话适用范围远超音频： 任何「A 组和 B 组分开采集」的对比，都在交这份税。

还有一个更坏的失败，在读数最后一行：「反了」那一栏。 误差棒不跨 0，你信心满满写进报告，但方向是反的。 它的比例通常只有 1–2%，靠手点很难撞上——但你一年做几十次对比测试，它就会来找你一两回。 这种失败最危险，因为它看起来像个结论。

五、跑一个真的：把「全双工」变成一个等级

第 3 课说过：「全双工」这个卖点要用双讲用例验收，不能只测单人轮流说。 但当时没给你验收的刻度。P.340 §8 给了，而且它天生就是一个差值—— 正好是本课方法的完美示范。

要测的量 双讲衰减量 aH,S,DT：本机说话人的声音送出去的电平， 在对方也在说话时，比只有本机在说话时低了多少 dB。

衰减 0 dB = 对方插话完全不影响你——真全双工。 衰减 15 dB = 对方一开口你就被压掉大半——那是半双工套了个全双工的壳。

注意它是两个电平相减。所以你不需要知道任何一个电平的绝对准确值—— 只要两次测量在同一场、同一素材、同一增益下完成，误差就在相减时抵消了。这正是配对四规则。
步骤做什么为什么这么做
1 被测摄像机固定好，正前方 50 cm 放一只喇叭当「本地说话人」，播 P.501 语音（约 65 dB SPL） 喇叭可复现，真人不可复现。50 cm / 65 dB 直接抄 P.340，省掉自己定标准
2 另一台设备接通对讲，当「远端」。远端也用播放文件说话，不用真人 同上。而且远端素材必须每次一模一样，否则双讲的重合时刻会变
3 单讲：只放本地素材，远端静音。在远端录下收到的音频 这是你的参照。录音设备的增益从此不许动
4 双讲：本地素材不变，同时放远端素材。同样在远端录 唯一变量是「远端有没有在说话」
5 两段录音里截出同一句话的同一段，算各自的 RMS 电平 必须是同一句——不同句子本身响度就不同，那是新的变量
6 aH,S,DT = 单讲电平 − 双讲电平，查下表 差值。绝对刻度在这一步被消掉了

诚实声明：这是近似，不是合规 P.340 原版要用消声室、人工嘴、人工头和 CSS 复合测试信号，电平和带宽都有严格规定。 上面这套用喇叭 + 录音笔的做法拿不到合规结论，不能对外声称「符合 P.340 Behaviour 1」。

但它完全够用于：给三台竞品排序、验证固件改动有没有把双讲搞坏、 以及在评审桌上把「我们是全双工」逼成「衰减 8 dB，属于 2b」。 这正是第一节那三个问题的分工——你在做后两个，不是第一个。

评测条款 · 可直接抄进需求文档或发给供应商

  • 任何音频指标必须带条件：距离、声源电平 dB SPL、环境噪声 dB(A)、被测功能开关状态。缺一条就退回。
  • 要成对的数：降噪报 SNRI 必须同时报 DSN；波束成形报 DI 必须同时报 WNG；从不接受单边好消息。
  • 全双工写等级不写形容词：要求供应商给 P.340 Behaviour 等级及双讲衰减量 dB，不接受「支持全双工」。
  • 要求对比测试同场完成：竞品对比、版本对比必须同一天同一房间同素材，报告里写明。
  • 要求给出重复次数与波动范围，不接受单次测量的一个数。差值小于波动范围时视为无差异。
  • 回归门槛写差值：如「相对基线版本，双讲衰减量恶化不得超过 2 dB」，而不是「双讲衰减量 ≤ 6 dB」。
  • 素材统一：全项目使用同一套 P.501 语音与噪声素材，版本入库，不许各测各的。
  • 只有需要对外声称的绝对数才外包实验室，其余全部内部跑——预算花在刀刃上。
